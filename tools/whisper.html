About Whisper

Whisper is a family of open-source speech recognition models released by OpenAI. It transcribes spoken audio into text and the multilingual large-v3 models can translate speech from many languages directly into English. The weights are published under the permissive MIT license, so you can download them and run them on your own hardware.

The current open release is large-v3-turbo, an optimized version of large-v3 released in September 2024. It keeps almost all of the accuracy of the full large-v3 model while running about 8x faster, which makes it far more practical for batch jobs and near-real-time use. The full large-v3 checkpoint is still available when you want the highest possible quality. Turbo itself is not trained for translation tasks; use the other multilingual large-v3 checkpoints for speech-to-English translation.

Alongside the open models, OpenAI offers hosted transcription through its API. The original endpoint, whisper-1, has been joined by newer models: gpt-4o-transcribe, gpt-4o-mini-transcribe, and gpt-transcribe, which OpenAI now recommends as the default for recorded speech. Speaker diarization is handled by a separate model, gpt-4o-transcribe-diarize, and live streaming is handled by gpt-live-transcribe, with gpt-realtime-whisper and gpt-realtime-translate also listed on OpenAI's pricing page.

Pricing splits into two tracks. The open-source models are free to use — you only pay for your own compute. The hosted API is billed per minute of audio: whisper-1 and gpt-4o-transcribe are $0.006/min, gpt-4o-mini-transcribe is $0.003/min, gpt-transcribe is $0.0045/min, gpt-4o-transcribe-diarize is $0.006/min, gpt-live-transcribe and gpt-realtime-whisper are $0.017/min, and gpt-realtime-translate is $0.034/min.

Accuracy varies a lot by language. Whisper was trained on around 99 languages, but quality is strongest for high-resource languages like English and drops noticeably for less common ones. Running the larger models locally also needs a capable GPU, and the model can occasionally hallucinate text during long silences.

Whisper is a good fit if you want a free, self-hostable transcription engine, need broad multilingual coverage, or want a managed API without building your own pipeline. Choose the hosted gpt-4o-transcribe-diarize or gpt-live-transcribe models if you need diarization or live streaming out of the box.

Advantages
  • Open-source under the MIT license, free to self-host with no usage fees
  • large-v3-turbo runs about 8x faster than large-v3 with only a small accuracy loss
  • Broad multilingual support, trained on roughly 99 languages, with speech-to-English translation available in the non-turbo large-v3 checkpoints
  • Flexible deployment: run the open weights locally or use the hosted OpenAI API
  • Hosted API offers dedicated diarization (gpt-4o-transcribe-diarize) and live streaming (gpt-live-transcribe) models
Disadvantages
  • Accuracy drops significantly for low-resource languages compared to English
  • The larger open models need a capable GPU for reasonable speed
  • Can hallucinate phantom text during long silences or noisy segments
  • Self-hosting requires technical setup; there is no official desktop app
  • large-v3-turbo is not trained for translation, so you need a different checkpoint for that

Choose Whisper if…

  • You want a free, self-hosted transcription engine you fully control
  • You need to transcribe or translate audio across many languages using the large-v3 models
  • You prefer a managed API and are fine paying roughly $0.0045-0.006/min for gpt-transcribe, whisper-1, or gpt-4o-transcribe
  • You need live streaming transcription (gpt-live-transcribe) or speaker diarization (gpt-4o-transcribe-diarize) via OpenAI's hosted API
  • You want maximum throughput and pick large-v3-turbo for its ~8x speed, but don't need translation

Frequently Asked Questions

What is OpenAI Whisper?
Whisper is OpenAI's open-source speech recognition model. Released in 2022, it transcribes audio in around 99 languages with high accuracy. It's a developer tool — not a consumer app — that runs locally or via API. Many transcription apps are built on top of Whisper.
Is Whisper free?
Whisper's open-source weights are completely free to download and run locally. OpenAI also offers Whisper-based models through its API on a per-minute basis, starting around $0.003/min for gpt-4o-mini-transcribe, with whisper-1 at $0.006/min. Consumer apps built on Whisper typically charge their own subscription fees.
