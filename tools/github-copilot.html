About GitHub Copilot

GitHub Copilot started as an in-editor autocomplete tool, but the current 2026 product is a full multi-model coding platform. It lives inside your editor, in the terminal and on GitHub itself, handling code completion, chat, an agent mode that edits across files, cloud agents that work on tasks asynchronously, and automated code review.

The biggest recent change came on June 1, 2026, when Copilot moved from premium request units to consumption-based GitHub AI Credits, a token-based system. Every plan now includes a monthly credit allowance, with pay-as-you-go overages and new admin budget and spending caps. The older automatic fallback to cheaper models was discontinued, and code review now also consumes GitHub Actions minutes.

The core capabilities today are agent mode, cloud agents, chat, code review, a CLI, and the ability to pick which frontier model you want, including Claude Sonnet 5, Claude Opus 4.8, GPT-5.5 and Gemini 3.1 Pro. Code completions and Next Edit suggestions stay included and do not draw down your credit allowance.

On pricing, individuals can choose Free at 0 dollars a month (around 2,000 completions, limited chat and agent use, automatic model selection), Pro at 10 dollars a month (unlimited completions, model selection, cloud agents, a monthly credit allowance), Pro+ at 39 dollars a month (premium frontier models including Opus and a higher allowance), or Max at 100 dollars a month (the highest allowance and priority access to new models). Verified students get Pro-level access free. Organizations pick Business at 19 dollars per user a month (including 19 dollars of monthly AI Credits) or Enterprise at 39 dollars per user a month (including 39 dollars of credits, codebase indexing and GitHub.com chat). Promotional bonus credits run June through August 2026: Business plus 30 dollars a month, Enterprise plus 70 dollars a month.

The main limitation is cost predictability: usage-based billing means heavy agent, chat or frontier-model use can push you into overages, and code review burning Actions minutes adds a second meter to watch. Budgets and caps help, but teams need to monitor consumption.

Copilot is a strong fit if you already work in GitHub and VS Code, want an agentic assistant rather than plain autocomplete, and value being able to choose the underlying model. The free tier is a low-risk way to try it, while Pro+ and Max suit heavier users of premium models.

Frequently Asked Questions

What is Aider?
Aider is an open-source AI coding assistant that runs in the terminal. It connects to AI models (Claude, GPT-4, Gemini) and can edit multiple files simultaneously, automatically committing changes to git after each step.
Is Aider better than GitHub Copilot?
They serve different workflows. Aider is better for autonomous multi-file refactoring from the command line. Copilot is better for real-time inline suggestions inside an IDE. Many developers use both.
Is Aider free?
Aider itself is free and open-source. You pay for the AI model API you connect it to — Claude or GPT-4 API costs apply per token used.
Does GitHub Copilot work without GitHub?
GitHub Copilot requires a GitHub account but works in VS Code, JetBrains, Neovim, and Visual Studio regardless of where your code is hosted. You don't need to push code to GitHub to use it.
