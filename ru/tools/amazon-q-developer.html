GitHub Copilot Freemium
ИИ-кодинг в VS Code, облачные агенты, код-ревью, выбор модели среди разных поставщиков

GitHub Copilot — это агентный, мультимодельный помощник для кодинга, который выходит за рамки автодополнения, предлагая чат, агентный режим, облачных агентов, код-ревью и CLI, с моделями от таких поставщиков, как Anthropic, OpenAI, Google, xAI, Microsoft и Moonshot. Использование тарифицируется через GitHub AI Credits, с уровнями от бесплатного плана до индивидуальных и организационных планов.

Cursor Freemium
AI IDE, агентное программирование, мульти-репозитории, ревью PR, параллельные агенты

Cursor — это ориентированный на ИИ редактор кода, построенный на базе VS Code, с агентным программированием, поддержкой нескольких репозиториев, параллельными агентами и автоматическим ревью PR. Новые клиенты теперь регистрируются через The X Subscription — пакет, объединяющий Cursor с Grok от xAI и X Premium, при этом другие сторонние модели оплачиваются отдельно по цене API.

Cline Freemium
Автономный агент для написания кода с пошаговым подтверждением действий, доступный в VS Code, JetBrains, CLI и в виде десктоп-приложения

Автономный AI-агент для написания кода с открытым исходным кодом, доступный в виде расширения для VS Code, плагина для JetBrains, CLI и нативного десктоп-приложения — создаёт файлы, выполняет команды в терминале и управляет браузером, при этом каждое действие требует подтверждения пользователя. Работает с любой LLM через собственный API-ключ или через собственного провайдера инференса Cline.
