Claude Code Paid
Сложный многофайловый рефакторинг и агентные рабочие процессы

Claude Code — это ИИ-агент для написания кода от Anthropic, в настоящее время версия CLI 2.1.291 (октябрь 2026 года), с Claude Opus 5.5 в качестве модели по умолчанию. Он работает в терминале, VS Code, JetBrains, десктопном приложении и в вебе, а также может управлять облачными агентами, субагентами и функцией computer use.

Cursor Freemium
AI IDE, агентное программирование, работа с несколькими репозиториями, ревью PR, параллельные агенты

Cursor — это AI-ориентированный редактор кода на базе VS Code с агентным программированием, поддержкой нескольких репозиториев, параллельными агентами и автоматизированным ревью PR. Собственная линейка моделей теперь включает Grok 4.7, Grok 4.6, Grok 4.5 и Composer 2.5, наряду с поддерживаемыми сторонними моделями.

GitHub Copilot Freemium
ИИ-кодинг в VS Code, облачные агенты, ревью кода, выбор модели среди разных поставщиков

GitHub Copilot — это агентный мультимодельный ассистент для разработки, который выходит далеко за рамки автодополнения, предлагая чат, агентный режим, облачных агентов, ревью кода и CLI, с моделями от таких поставщиков, как Anthropic, OpenAI, Google, xAI, Microsoft и Moonshot. Использование тарифицируется через GitHub AI Credits, с уровнями от бесплатного плана до индивидуальных и корпоративных планов.
