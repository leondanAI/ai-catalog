О сервисе Cursor

Cursor — это ориентированный на ИИ редактор кода, который начинался как форк VS Code, а теперь вырос в полноценную платформу для агентного программирования. Вместо того чтобы просто автодополнять строки, он может планировать и выполнять многоэтапные изменения в репозитории, запускать собственные проверки ревью и передавать задачи фоновым агентам.

С 12 октября 2026 года новые клиенты Cursor по умолчанию подключаются к The X Subscription — пакету, объединяющему Cursor с Grok от xAI, ботом Grok и X Premium под эгидой SpaceXSI. Grok и Cursor теперь используют общий еженедельный пул лимитов для подписчиков этого плана. Клиенты, у которых уже был старый отдельный план Cursor, могут его сохранить, но переход на The X Subscription является опциональным и, будучи выполненным, необратим.

Ключевые возможности включают агента Composer для крупных правок, облачных агентов и облачные среды разработки, запускаемые через /in-cloud, автоматическое ревью кода, а также Bugbot для автоматизированного ревью PR. Инструмент по-прежнему поддерживает сторонние модели, MCP-серверы, пользовательские правила и хуки, так что вы не привязаны к одному семейству моделей. Среди недавних дополнений — Projects (бета), самостоятельно размещаемые машины, а также боты Rollouts и Security Review для клиентов Teams и Enterprise.

В рамках The X Subscription Cursor предлагается в пяти тарифах: Free, Plus за $8 в месяц, Premium за $30 в месяц, Super за $100 в месяц и Ultra за $200 в месяц. Эти тарифы используют общий еженедельный пул лимитов для Grok и Cursor. Сторонние модели, такие как Claude или GPT, не включены ни в один тариф; их использование в Cursor оплачивается отдельно по прайс-листу API из предоплаченного кредита.

Основные ограничения — непредсказуемость стоимости и необратимость перехода: после перехода на The X Subscription вернуться к отдельному плану Cursor нельзя, а использование сторонних моделей сверх любого тарифа оплачивается по цене API из предоплаченного кредита, что может быть трудно спланировать в бюджете. Будучи форком VS Code, инструмент иногда отстает от апстрим-расширений, а самые мощные функции предполагают, что вы готовы позволить агенту вносить масштабные изменения.

Cursor подходит разработчикам, которые хотят получить агента, способного решать реальные многофайловые задачи, а не просто предлагать фрагменты кода, и которые готовы принять связанную экосистему Grok/X. Это хороший выбор для профессиональных команд, уже работающих в VS Code, и менее привлекательный вариант для тех, кто хочет только легкое автодополнение, работает вне VS Code или хочет избежать пакетного ценообразования экосистемы X.

Частые вопросы

Что такое Cursor?
Cursor — это нативная для ИИ IDE на базе VS Code. Она дает ИИ полный контекст вашей кодовой базы и может редактировать несколько файлов, выполнять команды терминала и завершать задачи от начала до конца в режиме агента.
Сколько стоит Cursor?
Новые клиенты регистрируются через The X Subscription, которая имеет пять тарифов: Free, Plus за $8 в месяц, Premium за $30 в месяц, Super за $100 в месяц и Ultra за $200 в месяц. Эти тарифы используют общий еженедельный пул лимитов для Grok и Cursor. Сторонние модели, такие как Claude или GPT, не включены ни в один тариф и оплачиваются отдельно по прайс-листу API из предоплаченного кредита. Клиенты, у которых уже был старый план Cursor, могут его сохранить, но переход на The X Subscription является опциональным и необратим.
Безопасно ли использовать Cursor с моей кодовой базой?
В текущем описании не детализируются конкретные функции конфиденциальности или соответствия требованиям, но Cursor предлагает тариф Enterprise с индивидуальными условиями, где обычно и реализуются более строгий контроль данных и управление на уровне команды.
Какие модели использует Cursor?
Встроенная модель Cursor — Grok от xAI, включенная во все тарифы The X Subscription и использующая общий еженедельный пул лимитов с Cursor. Cursor также поддерживает сторонние модели от таких поставщиков, как OpenAI, Anthropic и Google, оплачиваемые отдельно по цене API из предоплаченного кредита, и вы можете переключать модели для каждого запроса в настройках.
