О сервисе Kiro

Kiro — агентная IDE Amazon на базе спецификаций, объявленная в мае 2026 как официальная замена плагина Amazon Q Developer IDE. Amazon заблокировал новые регистрации на плагин Q Developer с 15 мая 2026, полная поддержка плагина завершится 30 апреля 2027. Kiro представляет стратегическое репозиционирование Amazon в сфере AI-инструментов для разработчиков.

Ключевая концепция — Specs. Spec — это документ на естественном языке, описывающий требования, архитектурные решения и ограничения реализации для функции или компонента. Вместо написания кода разработчик пишет Spec — Kiro читает его и автономно генерирует полную реализацию: создаёт файлы, пишет функции, обрабатывает крайние случаи и связывает компоненты.

Hooks — событийный слой автоматизации Kiro. Hooks срабатывают при событиях файловой системы (сохранение файла, git commit) и запускают действия агента. При сохранении — запускают тесты, линтинг или обновление документации. При коммите — сканируют безопасность, обновляют changelog или проверяют соответствие реализации Spec.

Kiro построен как IDE совместимая с VS Code — существующие расширения, горячие клавиши и конфигурации рабочего пространства работают без миграции. Агентный слой работает на Amazon Bedrock с доступом к Claude, Amazon Nova и другим моделям. Глубокая интеграция с AWS позволяет провизионировать инфраструктуру и деплоить в AWS прямо из IDE.

Kiro доступен по модели freemium. Бесплатный тариф поддерживает индивидуальных разработчиков с ограниченным использованием агента. Платные тарифы доступны для команд и предприятий. Kiro лучше всего подходит для инженеров и команд в AWS-окружениях, которые хотят агента, способного выполнить полную реализацию из структурированных требований.

  • Hooks: событийная автоматизация при сохранении файла и git commit — встроенные проверки качества
  • Работает на Amazon Bedrock с доступом к Claude, Amazon Nova и другим моделям

Недостатки

  • Новый продукт, заменяющий Amazon Q Developer — экосистема меньше, чем у Cursor
  • Качество агента на сложных Specs ещё проходит проверку в производственных условиях

Частые вопросы

Что такое Kiro?
Kiro — агентная IDE Amazon на базе спецификаций, запущенная в мае 2026 как замена плагина Amazon Q Developer IDE. Разработчики пишут Specs на естественном языке, описывая что нужно построить, а Kiro автономно генерирует полную реализацию.
Сколько стоит Kiro?
Kiro доступен по модели freemium. Бесплатный тариф для индивидуальных разработчиков с ограниченным использованием агента. Платные тарифы для команд и предприятий доступны на kiro.dev.
Что такое Kiro Specs?
Specs — документы на естественном языке, описывающие требования и ограничения реализации для функции. Kiro читает Spec и автономно генерирует код, файлы и архитектуру — связывая бизнес-требования с реализацией.
Что такое Kiro Hooks?
Hooks — событийные автоматизации, срабатывающие при действиях разработчика: сохранение файла или git commit. Они могут автоматически запускать тесты, обновлять документацию или сканировать безопасность — встраивая проверки качества в рабочий процесс.
