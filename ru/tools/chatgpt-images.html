О сервисе ChatGPT Images

ChatGPT Images — это система генерации изображений от OpenAI, доступная внутри ChatGPT и через OpenAI API. Текущее поколение — GPT Image 2.5, выпущенное 8 сентября 2026 года, которое пришло на смену GPT Image 2 от апреля. DALL·E 2 и DALL·E 3 были выведены из эксплуатации в мае 2026 года.

GPT Image 2.5 поставляется в виде двух моделей. Flare (gpt-image-2.5-flare) описывается OpenAI как самая быстрая модель для качественной повседневной генерации изображений. Sunburst (gpt-image-2.5-sunburst) — самая мощная модель для генерации и редактирования изображений, предназначенная для рабочих процессов, где точность редактирования важнее всего. Sunburst поддерживает редактирование изображений с inpainting и настройками качества от low до max. Обе модели принимают текст и изображения на входе и возвращают изображения.

Подход, ориентированный на рассуждение, появившийся с GPT Image 2, — это то, что отличает данную линейку: модель прорабатывает композицию и ограничения перед рендерингом, что заметно в деталях, с которыми модели генерации изображений исторически справлялись плохо — мелкий текст, иконки, элементы интерфейса и плотные макеты. GPT Image 2 также ввела Thinking Mode в ChatGPT для платных тарифов, генерирующий до 8 согласованных изображений на один запрос с сохранением персонажей на протяжении всего набора.

В ChatGPT генерация изображений доступна на бесплатном тарифе с ограниченным доступом и на платных тарифах, начиная с Plus за $20/месяц. Через API Flare и Sunburst стоят одинаково: $8 за миллион входных токенов изображения ($2 при кэшировании), $30 за миллион выходных токенов изображения и $5 за миллион входных текстовых токенов. Это дешевле, чем более старые модели по стоимости выходных данных — GPT Image 1.5 стоит $32, а GPT Image 1 — $40 за миллион выходных токенов.

Ограничения носят скорее практический, чем технический характер. Самый мощный вариант не является самым быстрым, поэтому в каждом рабочем процессе приходится выбирать между Flare и Sunburst. Ценообразование API на основе токенов делает стоимость одного изображения менее предсказуемой, чем фиксированная цена за изображение. А для чисто художественной работы стилистический диапазон остаётся более узким, чем у Midjourney.

ChatGPT Images подходит людям, которые уже работают в ChatGPT и хотят получать изображения без переключения между инструментами, разработчикам, которым нужна генерация текста и изображений из одного API, и командам, которые редактируют существующие изображения, а не создают их заново. Используйте Flare для быстрых черновиков и большого объёма, Sunburst — когда точность редактирования важнее скорости.

Преимущества
  • Два варианта по одной цене: Flare для быстрой повседневной генерации, Sunburst для точного редактирования
  • Качественная отрисовка мелкого текста, элементов интерфейса и плотных макетов благодаря подходу GPT Image 2, ориентированному на рассуждение
  • Редактирование изображений с inpainting через API, с настройками качества до max в Sunburst
  • Дешевле моделей, которые она заменяет: $30 за миллион выходных токенов против $32 у GPT Image 1.5 и $40 у GPT Image 1
  • Встроена в ChatGPT и доступна через тот же API OpenAI, что и текстовые модели
Недостатки
  • Расширенные функции работы с изображениями в ChatGPT доступны только на платных тарифах; у бесплатных пользователей доступ ограничен
  • Самый мощный вариант, Sunburst, не является самым быстрым — в каждом рабочем процессе приходится выбирать между скоростью и точностью
  • Ценообразование API на основе токенов делает стоимость одного изображения менее предсказуемой, чем фиксированная цена за изображение
  • Стилистический диапазон по-прежнему уже, чем у Midjourney, для чисто художественной работы

  • Вы хотите генерировать изображения внутри рабочего процесса ChatGPT без переключения между инструментами

  • Вы быстро генерируете множество черновиков и хотите самый быстрый вариант — используйте Flare
