GPT-5.4 вышел в трёх вариантах с контекстом 1 млн токенов

Модели Apr 16, 2026·OpenAI Blog

OpenAI расширила линейку моделей, выпустив GPT-5.4 в трёх вариантах: Standard, Thinking и Pro. Все три версии имеют единую архитектуру и контекстное окно в 1,05 миллиона токенов — наибольшее из всех коммерческих предложений OpenAI.

Три варианта

Standard оптимизирован для скорости и стоимости, подходит для большинства повседневных задач. Thinking добавляет расширенный слой рассуждений для сложных задач. Pro сочетает максимальные возможности с наибольшим контекстным окном для самых требовательных случаев использования.

Динамическая загрузка инструментов

Важное архитектурное изменение в GPT-5.4 — динамическая загрузка спецификаций инструментов. Вместо загрузки всех определений инструментов в начале каждого разговора, модель запрашивает только нужные спецификации по мере возникновения задач. Это снижает объём промпта и улучшает качество ответов в сложных агентных рабочих процессах.

Доступность

GPT-5.4 Standard сразу доступен подписчикам ChatGPT Plus. Варианты Thinking и Pro доступны через API и для клиентов ChatGPT Team и Enterprise.
