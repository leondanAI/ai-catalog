С 20 до 200+ принятых PR в месяц: как один инженер работает с Claude Code

Инструменты Nov 3, 2026·The Pragmatic Engineer

Рассылка The Pragmatic Engineer провела конкурс эссе среди читателей, и работа-победитель, опубликованная 3 ноября, — рассказ из первых рук о том, как выглядит программирование с ИИ на полной скорости. Автор, Нил Каккар, работает девять лет, в том числе в Bloomberg и PostHog, а сейчас он первый инженер стартапа Tano, где около десяти человек.

Цифры

На прошлых работах Каккар принимал от 8 до 20 пул-реквестов в месяц. В Tano — больше 200, примерно в 11 раз больше, чем в PostHog. Откатов, по его словам, примерно в шесть раз меньше — в основном потому, что ошибки исправляют следующим изменением, а медианное время от открытия PR до слияния — меньше часа. Вся команда сливает около 30 PR в день.

Как устроена работа

Всё держится на Claude Code. У каждого инженера одна подписка Claude Max 20x; Каккар оценивает, что по ценам API его расход стоил бы больше $8 000 в месяц. Он работает в настольном приложении Claude Code со встроенным браузером, а не в командной строке, ведёт 3–5 задач параллельно и даёт агентам по час-два на каждую функцию, включая их собственные проверки и скриншоты. Каждый PR автоматически проверяет агент Claude Code в GitHub Actions, а для рискованных изменений есть более глубокий агент-ревьюер. На большинстве PR этот агент — единственный проверяющий. Контекст по каждой части продукта записан в файлах AGENTS.md, чтобы агенты могли его найти.

Что пошло не так

Ошибки он перечисляет прямо. Агент умножил денежные суммы на 100, что неверно для валют вроде бахрейнского динара; это заметили после выкладки и исправили за час. Блокирующая миграция базы на большой таблице остановила приём данных. Другая миграция без защитных проверок дважды заплатила части авторов. Такие правила теперь записаны в инструкциях агента-ревьюера.

Человеческая цена тоже в списке: постоянное переключение между задачами, всё меньше людей, знающих конкретный кусок кода, шаблонный дизайн и упор в лимиты тарифа, когда агенты крутятся в циклах. Собственное правило Каккара — заканчивать в 18:00 и оставлять рабочие устройства в офисе.

Оговорка редактора

Гергей Орос, автор рассылки, добавляет, что по отрасли число PR с января выросло примерно вдвое, так что этот случай сильно выше среднего, а одна скорость ещё не доказывает, что продукт успешен. Зрелым компаниям, считает он, стоит менять процессы осторожнее.

Что это значит, если вы выбираете агента для кода

Выигрыш дал процесс, а не только инструмент. Записанный контекст, автоматический ревьюер на каждом PR и правила, выученные на инцидентах, сделали не меньше, чем модель.

Закладывайте лимиты. Даже старший тариф Claude заканчивался, когда агенты работали в циклах, поэтому проверьте лимиты, прежде чем строить планы на ночные прогоны. Если сравниваете варианты, смотрите Codex и Claude Code и наш список нейросетей для программирования.
