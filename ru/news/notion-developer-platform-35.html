Notion Developer Platform 3.5 — среда выполнения Workers, односторонняя синхронизация баз данных, двунаправленные вебхуки и новые API для агентов

Инструменты May 13, 2026·Notion Blog

Notion выпустила Developer Platform 3.5 13 мая 2026 года — самое значительное обновление для разработчиков за всю историю компании. Релиз представляет несколько новых возможностей, которые превращают Notion из рабочего пространства для знаний в программируемую платформу с агентным выполнением ИИ.

Среда выполнения Workers

Workers runtime — это хостинговая среда выполнения Notion для пользовательского кода, развёртываемого через новый Notion CLI и выполняемого в изолированной среде внутри Notion. Логика — автоматизация, преобразование данных, интеграции — теперь находится рядом с контентом, а не во внешних сервисах. База данных Notion теперь может запускать функцию, обрабатывать данные, вызывать внешний API и записывать результаты обратно — всё это в рамках среды Notion без использования Zapier, Make или специальной серверной инфраструктуры. Workers бесплатны на период бета-тестирования, а с 11 августа 2026 года будет введена оплата на основе кредитов Notion.

Database Sync

Database Sync, которая сейчас находится в бета-версии, позволяет Workers получать данные из внешних API и импортировать их в базы данных Notion — например, напрямую импортировать тикеты из Zendesk или записи из Salesforce в Notion. Соединение одностороннее: внешние данные поступают в Notion, что даёт командам живое, постоянно обновляемое представление информации, которое ранее требовало ручного импорта или разовой автоматизации.

Двунаправленные вебхуки и новые API для агентов

Двунаправленные вебхуки расширяют модель событий в обоих направлениях: Notion может получать входящие вебхуки от внешних сервисов для запуска рабочих процессов и отправлять исходящие вебхуки при изменении контента в Notion. Релиз также вводит новые возможности для агентов: External Agents API (альфа-версия) для подключения внешних агентов к Notion, пользовательские инструменты для агентов, созданные как Workers (бета-версия), и Notion Agent SDK (альфа-версия) для создания агентов, работающих со структурированными данными Notion.

Почему это важно

Developer Platform 3.5 позиционирует Notion как платформу, где пользовательский код и агенты работают со структурированными, взаимосвязанными данными, а не только с документами. Для команд, уже использующих Notion в качестве операционного центра, Workers и Database Sync открывают возможности автоматизации и интеграции, которые раньше требовали специальной инженерной работы. Для разработчиков ИИ новые API и SDK для агентов открывают базы данных Notion как основу для создания автономных агентных рабочих процессов.
