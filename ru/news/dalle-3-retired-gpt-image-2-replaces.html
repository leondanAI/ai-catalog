OpenAI прекращает поддержку DALL-E 2 и DALL-E 3, рекомендует gpt-image-2 и другие модели в качестве замены

Модели May 12, 2026·OpenAI Blog

OpenAI официально отключила DALL-E 2 и DALL-E 3 в своём API 12 мая 2026 года, завершив эпоху линейки продуктов DALL-E. О прекращении поддержки было объявлено 14 ноября 2025 года, при этом OpenAI рекомендовала в качестве замены gpt-image-2, gpt-image-1 или gpt-image-1-mini. gpt-image-2 — это единая модель генерации изображений, которая лежит в основе ChatGPT Images 2.0 и доступна через API OpenAI.

Что нового в gpt-image-2

Новая модель обеспечивает нативный вывод с разрешением 2K без апскейлинга — значительный скачок качества по сравнению с максимумом DALL-E 3 в 1792×1024 пикселей. Многоязычный рендеринг текста позволяет gpt-image-2 точно генерировать читаемый текст на нелатинских письменностях, включая арабский, китайский, иврит и кириллицу — возможность, с которой DALL-E 3 справлялась плохо. В режиме «размышления» модель поддерживает до 8 изображений на один запрос, что позволяет быстро создавать вариации для задач дизайна и маркетинга.

Влияние на API и разработчиков

Существующие интеграции с API, использующие эндпоинты DALL-E 3, требуют перехода на одну из рекомендованных моделей-замен. Потребительская версия новой модели, ChatGPT Images 2.0, была запущена 21 апреля 2026 года. Базовая модель доступна всем пользователям ChatGPT, тогда как функции «размышления» зарезервированы для подписчиков Plus, Pro, Business и Enterprise. Цены на API для gpt-image-2 устанавливаются за изображение при разрешениях от 512px до 2K, с оптовыми тарифами для пользователей API с большими объёмами запросов.

Почему это важно

Прекращение поддержки бренда DALL-E спустя четыре года свидетельствует о переходе OpenAI к единой схеме наименования моделей, в рамках которой генерация изображений становится функцией семейства моделей GPT, а не отдельной продуктовой линейкой. Для пользователей и разработчиков непосредственная выгода заключается в существенно улучшенном качестве изображений и работе с текстом — что особенно ценно для локализованного маркетингового контента, требующего нелатинского текста.
