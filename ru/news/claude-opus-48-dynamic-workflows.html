Claude Opus 4.8 — скачок на 27 пунктов по математике, Dynamic Workflows, дешевле Fast режим

Модели May 28, 2026·Anthropic Blog

Anthropic запустила Claude Opus 4.8 28 мая 2026 года — всего через 41 день после Opus 4.7. Релиз позиционируется как значительное обновление качества жизни: более быстрые ответы, лучшая согласованность контекста и драматический скачок в математическом мышлении.

Математический бенчмарк: 69,3% до 96,7%

Наиболее впечатляющее улучшение — это USAMO 2026 — бенчмарк Математической олимпиады США. Opus 4.8 набирает 96,7%, по сравнению с 69,3% на Opus 4.7. Это скачок на 27 пункта за 41 день, что делает Opus 4.8 самой мощной общедоступной моделью в области продвинутой математики.

Opus 4.8 также примерно в четыре раза менее вероятно пропустить ошибки в собственном коде без их обнаружения и проактивно сигнализирует об неопределённости вместо того, чтобы уверенно галлюцинировать.

Динамические рабочие процессы в Claude Code

Самая крупная агентская функция — это Dynamic Workflows: Claude Code теперь может спланировать большую задачу, запустить до 1000 параллельных подагентов, распределить работу между ними и проверить результаты на соответствие вашему набору тестов — всё без участия человека. Функция разработана для миграций масштаба репозитория и рефакторинга сотен тысяч строк кода, которые раньше требовали команды инженеров.

Цена: та же базовая, дешевле режим Fast

Стандартная цена остаётся на уровне $5 за миллион входящих токенов и $25 за миллион выходящих токенов — идентично Opus 4.7. Главное изменение — в режиме Fast: он снижается с $30/$150 за миллион токенов (Opus 4.7) до $10/$50 — сокращение стоимости в 3 раза для рабочих нагрузок, критичных по задержке. Кэширование подсказок обеспечивает экономию до 90%; пакетная обработка дает скидку 50%.

Opus 4.8 доступна в Claude.ai для подписчиков Pro, Max, Team и Enterprise, а также через API Anthropic, AWS Bedrock, Google Cloud Vertex AI и Microsoft Foundry.

Mythos Preview скоро появится

Отдельно Anthropic подтвердила, что Claude Mythos Preview — модель кибербезопасности с ограниченным доступом — будет доступна утверждённым организациям «в ближайшие недели». За время 30-дневного превью Mythos и примерно 50 партнёрских организаций выявили более 10 000 уязвимостей высокого или критического уровня серьёзности в системно важном ПО.
