Claude Opus 4.8 добавляет динамические рабочие процессы, удешевляет быстрый режим и реже пропускает ошибки в коде

Модели May 28, 2026·Anthropic Blog

Anthropic выпустила Claude Opus 4.8 28 мая 2026 года — спустя 42 дня после Opus 4.7, которая была выпущена 16 апреля 2026 года. Релиз позиционируется как значимое обновление, повышающее удобство использования: более быстрые ответы, лучшая согласованность при работе с длинным контекстом и улучшения по агентным и кодинговым бенчмаркам.

Улучшения в бенчмарках

Anthropic отметила прирост результатов на Terminal-Bench 2.1, OSWorld-Verified, Finance Agent v2 и Online-Mind2Web, а также улучшения в надёжности кодинга. Opus 4.8 также примерно в четыре раза реже пропускает незамеченными ошибки в собственном коде и проактивно сигнализирует о неуверенности, вместо того чтобы уверенно выдавать галлюцинации.

Dynamic Workflows в Claude Code

Главная агентная функция — Dynamic Workflows, исследовательская предварительная версия, которая позволяет Claude Code планировать крупную задачу, запускать сотни параллельных подагентов в рамках одной сессии, распределять между ними работу и проверять результаты по вашему набору тестов — всё это без вмешательства человека. Dynamic Workflows доступна в Claude Code на тарифах Enterprise, Team и Max и рассчитана на миграции масштаба целого репозитория и рефакторинг кода объёмом в сотни тысяч строк, для которых раньше требовалась целая команда инженеров.

Цены: база прежняя, быстрый режим дешевле

Стандартная цена остаётся на уровне $5 за миллион входных токенов и $25 за миллион выходных токенов — как и у Opus 4.7. Главное изменение — в быстром режиме: цена снижается с $30/$150 за миллион токенов (Opus 4.7) до $10/$50 — снижение стоимости в 3 раза для задач, чувствительных к задержкам. Кэширование промптов даёт экономию до 90%; пакетная обработка — скидку 50%.

Opus 4.8 доступна в Claude.ai для подписчиков Pro, Max, Team и Enterprise, а также через Anthropic API, AWS Bedrock, Google Cloud Vertex AI и Microsoft Foundry.

Расширение доступа к Mythos Preview

Отдельно Anthropic сообщила, что рассчитывает сделать модели класса Mythos — свои модели для кибербезопасности с ограниченным доступом — доступными для всех клиентов «в ближайшие недели». Mythos Preview уже использовался небольшим числом организаций: за 30-дневный период предварительного доступа Mythos и около 50 партнёрских организаций выявили более 10 000 уязвимостей высокой или критической степени опасности в системно значимом программном обеспечении.
