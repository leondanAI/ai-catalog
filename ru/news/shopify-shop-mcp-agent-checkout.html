Shopify запустила Shop MCP: любой AI-агент может искать среди более чем миллиарда товаров и оплачивать через Shop Pay

Инструменты Oct 13, 2026·Shopify

Shopify представила Shop MCP 13 октября. Это одно MCP-подключение, которое сразу даёт AI-агенту или приложению три возможности: искать товары в Shopify Catalog, где их больше 1 миллиарда, собирать корзины и оформлять оплату через Shop Pay. MCP (Model Context Protocol) — открытый стандарт, через который AI-ассистенты подключаются к внешним инструментам.

Как это работает

Сервер находится по адресу mcp.shop.com, и, по словам Shopify, к нему может подключиться любой MCP-клиент или ваш собственный код. Описание навыка, которое агенты могут прочитать сами, лежит по адресу mcp.shop.com/skill.md. Сервер предоставляет 17 инструментов: поиск и просмотр товаров, работу с корзиной и оформлением заказа, проверку статуса оплаты и поиск заказов с отслеживанием доставки для вошедших покупателей.

Для поиска API-ключ не нужен. Корзины и оформление заказа тоже работают без входа в аккаунт. Чтобы заплатить через Shop Pay, покупатель входит через Shop — тогда при оформлении подставляются его сохранённые адреса и Shop Pay. Как пишет Shopify, в MCP-клиентах вроде Claude и ChatGPT этот вход они берут на себя, а в собственном коде можно использовать device flow.

Кто нажимает «купить»

По умолчанию покупатель платит сам — на странице оформления заказа у продавца, по ссылке, которую передаёт агент. Вошедший покупатель может поручить завершить покупку агенту, но только после того, как сам подтвердит сумму и способ оплаты. Каждое оформление относится к одному продавцу, так что товары из трёх магазинов — это три отдельных заказа.

У продавцов заказы, сделанные через агента, появляются в админке Shopify как обычные. Вебхуков на старте нет, поэтому статус оплаты разработчикам придётся опрашивать самим. Существующие интеграции с Catalog API продолжают работать без изменений. Ещё Shopify выпустила консольную утилиту @shopify/shop для поиска прямо из терминала.

Что это значит, если вы покупаете или строите что-то с AI-агентами

Если вы пользуетесь AI-ассистентом для повседневных дел, покупки становятся одним из них. Claude и ChatGPT Shopify называет клиентами, которые сами обрабатывают вход через Shop. Прежде чем разрешить агенту завершить покупку, проверьте сумму, магазин и способ оплаты, которые он показывает: это подтверждение и есть встроенная в процесс защита.

Если вы выбираете ассистента, поддержка коннекторов теперь важна наравне с качеством ответов. Сравнение двух главных вариантов — в материале ChatGPT vs Claude.

Если вы разрабатываете агентов, Shop MCP — простой способ добавить поиск товаров: для старта не нужны ни ключ, ни интеграция с продавцом, а оплату можно подключить позже.
