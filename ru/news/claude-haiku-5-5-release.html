Claude Haiku 5.5: самая дешёвая и быстрая модель Anthropic теперь доступна и в бесплатной версии Claude

Модели Oct 7, 2026·Anthropic

Anthropic выпустила Claude Haiku 5.5 7 октября, назвав её самой дешёвой, быстрой и функциональной малой моделью из всех, что компания выпускала. Модель рассчитана на высоконагруженные задачи, чувствительные к скорости, — классификацию, извлечение данных, маршрутизацию, поддержку клиентов в реальном времени и работу с браузером.

Цена и лимиты

В API Haiku 5.5 стоит $0,10 за миллион входных токенов и $0,50 за миллион выходных для промптов до 100 000 токенов. Для более длинных промптов стоимость всего запроса составляет $0,50 и $2,50. Контекстное окно модели — 1 миллион токенов, максимум выходных токенов — 128 000. В Batch API цена вдвое ниже.

Что нового

Это первая модель Haiku с настраиваемым уровнем усилий — от минимального до максимального, что позволяет разработчикам жертвовать скоростью ради более вдумчивых ответов. Anthropic отмечает, что для сложного агентного программирования по-прежнему лучше подходят Sonnet 5.5 и Opus 5.5.

Где доступна модель

Пользователи тарифов Free, Pro, Max, Team и Enterprise могут выбрать Haiku 5.5 на Claude.ai, в веб-версии, а также в приложениях для iOS и Android. В API её идентификатор — claude-haiku-5-5, модель также доступна на Amazon Bedrock, Google Cloud и Microsoft Foundry. В Claude Code модель Haiku по умолчанию была переключена на версию 5.5 в тот же день.

Почему это важно

Haiku 5.5 делает линейку моделей Anthropic дешевле в нижнем сегменте: для задач, где скорость и цена важнее глубины анализа, это теперь одна из самых недорогих функциональных моделей на рынке.
