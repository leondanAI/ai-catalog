Sobre Claude Code

O Claude Code é a ferramenta de desenvolvimento agêntica da Anthropic. Ele lê a sua base de código, edita arquivos, executa comandos e consegue levar uma tarefa de um pedido em linguagem natural até uma alteração funcional, em vez de apenas sugerir autocompletar no editor.

A versão atual é a CLI v2.1.x (v2.1.185-v2.1.193, fim de junho de 2026). Desde 28 de maio de 2026 o modelo padrão é o Claude Opus 4.8, o modelo mais forte da Anthropic para computer use e agentes de navegador, que funciona com esforço alto por padrão (dá para aumentar com /effort xhigh). O modo rápido agora também roda no Opus 4.8, a $10/$50 por milhão de tokens, cerca de 3 vezes mais barato que os modelos anteriores.

Além do terminal, o Claude Code abrange web e celular. Entre as novidades recentes estão os 'fluxos dinâmicos' que orquestram de dezenas a centenas de subagentes, o modo Auto ampliado (agora no plano Pro e também no Bedrock, no Google Cloud e no Microsoft Foundry), computer use na CLI, a caça a bugs na nuvem /ultrareview, os Artifacts (beta), agentes de nuvem agendados (Routines), suporte nativo ao Windows sem Git Bash, /code-review e subagentes em segundo plano.

Preços: o plano gratuito ($0) não inclui o Claude Code. Ele vem incluído no Pro ($17/mês no anual ou $20/mês no mensal), no Max 5x (a partir de $100/mês), no Max 20x ($200/mês), no Team Premium ($100/assento/mês no anual, $125 no mensal, mínimo de 5 assentos) e no Enterprise (assento mais uso a tarifa de API a partir de $20/assento). O Team Standard custa $20/assento/mês no anual ($25 no mensal). O acesso via API é cobrado à parte: preço introdutório de $2/$10 por milhão de tokens até 31 de agosto de 2026, depois $3/$15; o modo rápido do Opus 4.8 é $10/$50.

Vale conhecer as limitações. Não há forma gratuita de usá-lo, há tetos de uso mesmo nos planos pagos (em 6 de maio de 2026 a Anthropic dobrou os limites e adicionou cobrança por excedente com teto de gasto) e o uso da API pode ficar caro em execuções agênticas grandes. Execuções de esforço alto podem ser lentas e consumir tokens rapidamente.

É indicado para desenvolvedores profissionais e equipes que querem um agente que de fato edita e entrega código, sobretudo quem já tem um plano Pro, Max ou Team e quer programação incluída sem uma fatura de API separada.

Perguntas frequentes

O que é o Claude Code?
O Claude Code é a ferramenta CLI oficial da Anthropic para engenharia de software. Funciona no terminal, lê sua base de código, escreve código, executa comandos, corrige bugs e completa tarefas de múltiplos arquivos como agente autônomo.
Quanto custa o Claude Code?
Incluído no Claude Pro ($20/mês), Max ($100/mês), Team e Enterprise. O uso é medido pelos tokens de API consumidos durante tarefas agênticas.
Como o Claude Code se diferencia do Cursor?
O Claude Code funciona no terminal — sem interface gráfica. É projetado para desenvolvedores que preferem workflows CLI. O Cursor é um IDE completo com interface visual baseado no VS Code.
O que o Claude Code pode fazer de forma autônoma?
Ler e editar arquivos, executar comandos shell, rodar testes, pesquisar na base de código, gerenciar git e completar tarefas de engenharia em múltiplas etapas com prompts mínimos.
