Cursor lança hospedagem de código própria — e agentes que iniciam sem repositório

Ferramentas Aug 17, 2026·Cursor

A Cursor passou agosto transformando um editor em infraestrutura. Três lançamentos que, juntos, apontam uma direção clara.

Origin: a Cursor hospeda seu código

Em 17 de agosto, a Cursor lançou o Origin, hospedagem de repositórios de código integrada, em beta inicial. Ele sincroniza com repositórios do GitHub de forma bidirecional em tempo real, gerencia pull requests com sincronização do GitHub e se integra com Vercel, Depot e Buildkite.

Um editor de IA lançar sua própria hospedagem de código é um movimento significativo. Significa que o agente não precisa mais cruzar uma fronteira de API para ler histórico, abrir branches ou gerenciar revisões.

Agentes sem repositório

Em 27 de agosto, os Cloud Agents deixaram de exigir o GitHub ou qualquer controle de versão de terceiros para começar a trabalhar. Um agente agora cria um repositório Origin em segundo plano, e o trabalho pode ser convertido depois em um repositório permanente, com nome e visibilidade escolhidos. Pré-visualização ao vivo no navegador e publicação na Vercel estão incluídas.

Isso elimina totalmente a etapa de configuração: descreva uma tarefa, obtenha código funcional com histórico, e decida depois se ele merece se tornar um projeto de verdade.

Máquinas auto-hospedadas

Em 2 de setembro, a Cursor adicionou máquinas auto-hospedadas, mantendo a execução de ferramentas dentro da própria rede do usuário. Há máquinas pessoais e pools de equipe, uso de computador em Linux e Mac com controle de desktop, além de suporte para AWS Lambda, Coder, Cloudflare, Daytona e Modal.

Esse é o destravamento para empresas. Muitas organizações não podem permitir que um agente execute código na infraestrutura de um fornecedor, e isso resolve essa objeção diretamente.

Por que isso importa

Vistas em conjunto, essas três mudanças deslocam a Cursor de "recursos de IA em um editor" para um lugar onde o código vive, roda e é publicado. O que também significa que o custo de troca está subindo: um repositório no Origin, agentes configurados em torno dele e execução em máquinas próprias representam um compromisso muito mais profundo do que um editor que se pode simplesmente trocar.

Vale ponderar antes de adotar o Origin como algo além de um espelho. A sincronização bidirecional com o GitHub torna isso fácil de fazer com segurança — mantenha o GitHub como fonte de verdade e deixe o Origin ser a cópia de trabalho.
