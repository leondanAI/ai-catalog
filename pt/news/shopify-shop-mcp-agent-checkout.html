Shopify lança Shop MCP: qualquer agente de IA pode buscar mais de 1 bilhão de produtos e finalizar compra com Shop Pay

Ferramentas Oct 13, 2026·Shopify

A Shopify anunciou o Shop MCP em 13 de outubro. Trata-se de uma única conexão MCP que dá a um agente ou aplicativo de IA três capacidades ao mesmo tempo: buscar no Shopify Catalog, que reúne mais de 1 bilhão de produtos, montar carrinhos e concluir o checkout com Shop Pay. MCP (Model Context Protocol) é o padrão aberto que assistentes de IA usam para se conectar a ferramentas externas.

Como funciona

O servidor é um endpoint remoto em mcp.shop.com, e a Shopify afirma que qualquer cliente MCP pode se conectar, assim como código próprio. Uma descrição de skill que os agentes podem ler por conta própria é publicada em mcp.shop.com/skill.md. O servidor expõe 17 ferramentas, incluindo busca e consulta de produtos, ferramentas de carrinho e checkout, status do checkout e busca de pedidos com rastreamento para compradores logados.

A busca não exige chave de API. Carrinhos e checkout também funcionam sem login. Para pagar com Shop Pay, o comprador faz login com o Shop, o que permite que o checkout use seus endereços salvos e o Shop Pay. Segundo a Shopify, clientes MCP como Claude e ChatGPT cuidam desse login, e código personalizado pode usar um fluxo de dispositivo (device flow).

Quem aperta o "comprar"

Por padrão, o comprador paga na própria página de checkout do lojista, por meio de um link que o agente repassa. Um comprador logado pode, em vez disso, deixar o agente concluir a compra, mas somente depois de confirmar o total e uma forma de pagamento. Cada checkout pertence a um único lojista, então itens de três lojas significam três checkouts.

Para os lojistas, pedidos feitos por meio de um agente aparecem no admin da Shopify como qualquer outro pedido. No lançamento, não há webhooks, então os desenvolvedores precisam consultar periodicamente (polling) o status do checkout. Integrações existentes com a Catalog API continuam funcionando sem alterações. A Shopify também lançou uma ferramenta de linha de comando, @shopify/shop, para buscas pelo terminal.

O que isso significa para quem compra ou desenvolve com agentes de IA

Se você usa um assistente de IA para tarefas do dia a dia, fazer compras está se tornando uma delas. Claude e ChatGPT são os clientes que a Shopify cita como responsáveis pelo login no Shop. Antes de deixar um agente concluir uma compra, verifique o total, a loja e a forma de pagamento exibidos, já que essa confirmação é a salvaguarda incorporada ao fluxo.

Se você está decidindo qual assistente usar, o suporte a conectores agora é um fator real tanto quanto a qualidade das respostas. Veja como os dois se comparam em ChatGPT vs Claude.

Se você desenvolve agentes, o Shop MCP é uma forma de baixo esforço para adicionar busca de produtos: não é preciso chave nem integração com o lojista para começar, e o checkout pode ser adicionado depois.
