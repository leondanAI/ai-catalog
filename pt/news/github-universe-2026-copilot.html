GitHub Universe 2026: app do Copilot do issue ao merge, roteamento de modelos com Copilot Fusion e Copilot para todos os clientes Enterprise

Ferramentas Oct 28, 2026·GitHub

O GitHub usou sua conferência Universe, em 28 de outubro, para reposicionar o GitHub Copilot, deixando de ser apenas um assistente de codificação para se tornar um sistema de conclusão de trabalho. Quatro anúncios são os mais relevantes para quem está escolhendo uma ferramenta de codificação.

O app do Copilot

Um novo aplicativo para desktop, atualmente oferecido para download em Macs com chips Apple, foi criado para levar uma tarefa do issue ao merge. Ele conecta agentes e ferramentas entre projetos e também abrange trabalhos ao redor do código, como redigir especificações e analisar telemetria. Dentro dele, os Copilot projects, disponíveis desde o lançamento, executam trabalho de agentes em vários repositórios em paralelo, com um único local para acompanhar o progresso. Uma sessão de agente na nuvem pode ser acompanhada e conduzida a partir do app, do VS Code, da CLI ou da web.

Copilot Fusion

O Fusion é um roteador de modelos: você o seleciona no menu de modelos e, para cada solicitação, ele escolhe quais modelos usar e de que forma, desde um único modelo até vários que rascunham, criticam e revisam. Está disponível de forma geral no VS Code, no Copilot CLI, no app do Copilot e em IDEs JetBrains. O Fusion Standard está disponível em todos os planos, incluindo o Free; o Fusion High exige Pro+, Max, Business ou Enterprise; o Fusion Max exige Max, Business ou Enterprise. Não há cobrança separada: você paga créditos de IA para cada modelo acionado.

O GitHub afirma que o Fusion Max obteve uma pontuação a apenas dois pontos do Claude Opus 5.5 Max no Artificial Analysis Coding Agent Index, pela metade do custo e em 40% menos tempo por tarefa. Essa é uma afirmação do próprio GitHub.

Code review Max

A revisão de código do Copilot ganha um terceiro nível, o mais completo, chamado Max, em pré-visualização pública. Ele usa vários modelos de alto raciocínio, e a documentação do GitHub indica um custo médio de cerca de $10 em créditos de IA por revisão, contra cerca de $1,50 no nível padrão Balanced e $0,25 no Lite.

Copilot incluído para o GitHub Enterprise

Clientes do GitHub Enterprise agora podem usar todos os recursos do Copilot, incluindo o app, a revisão de código e as automações, sem precisar comprar uma assinatura separada do Copilot. Eles pagam pelos créditos de IA que utilizam. Por enquanto, isso é feito por meio da equipe de vendas do GitHub, com autoatendimento prometido para mais adiante, e os atuais clientes do Copilot Business e Enterprise podem manter seus planos atuais. Para indivíduos, o Copilot é oferecido a $10 por mês no plano Pro, $39 no Pro+ e $100 no Max.

O que isso significa para quem está escolhendo um agente de codificação

Se sua empresa já paga pelo GitHub Enterprise, pergunte ao seu administrador sobre a opção baseada em créditos antes de comprar um agente de codificação separado: você pode obter o Copilot sem um novo contrato por usuário.

Se você está comparando o Copilot com o Claude Code, o Fusion e o code review Max aproximam ainda mais os produtos, e o custo agora depende dos créditos usados, em vez do número de usuários. Veja Claude Code vs GitHub Copilot.
