Claude Code Review chega à disponibilidade geral para Team e Enterprise, com níveis Quick, Standard e Deep

Ferramentas Oct 15, 2026·Anthropic

A Anthropic tirou o Code Review da prévia de pesquisa em 15 de outubro. Agora ele está disponível de forma geral para organizações nos planos Claude Team e Enterprise. O Code Review faz parte do Claude Code: assim que um administrador o ativa, o Claude revisa pull requests nos repositórios GitHub e comenta nas linhas que sinaliza.

Como funciona

Vários agentes leem a alteração e o código ao redor em paralelo, procurando erros de lógica, vulnerabilidades de segurança e casos extremos quebrados. Uma etapa de verificação checa cada descoberta em relação ao código para filtrar falsos positivos, e o restante é classificado por gravidade. A revisão publica comentários embutidos, um resumo e uma execução de verificação (check run). Ela nunca aprova nem bloqueia um pull request, então a decisão de fazer o merge continua com a equipe. Por padrão, ela procura bugs que quebrariam a produção, não formatação ou testes ausentes, e as equipes podem ajustá-la com um arquivo REVIEW.md.

O que mudou na disponibilidade geral

Velocidade: a Anthropic afirma que a maioria das revisões agora é concluída em 6 a 10 minutos, cerca de três vezes mais rápido do que os aproximadamente 20 minutos durante a prévia.
Níveis de revisão: Quick (mais rápido e mais barato), Standard (o padrão) ou Deep (mais minucioso, mais lento e mais caro), definidos para a organização e, se necessário, para cada repositório.
Quando é executado: cada repositório pode revisar uma vez quando um pull request é aberto, após cada push, ou apenas quando alguém comenta "@claude review".

Preço e disponibilidade

Não há um preço fixo por revisão. As revisões são cobradas com base no uso de tokens por meio de créditos de uso, separadamente do uso incluído no plano, e o custo depende do nível de revisão, do tamanho da alteração e da frequência com que as revisões são executadas. Os administradores podem definir um limite de gastos mensal. Organizações Enterprise elegíveis podem resgatar pelo menos $10.000 em créditos de Code Review até 15 de janeiro de 2027; os créditos expiram 30 dias após serem resgatados. O Code Review funciona com o GitHub, incluindo o GitHub Enterprise Server, e não está disponível para organizações com Zero Data Retention ou a configuração HIPAA.

A opção do GitHub, no mesmo dia

Também em 15 de outubro, o GitHub tornou geralmente disponível o AI Scan for pull requests. É mais restrito: procura vulnerabilidades de segurança nas alterações de pull requests, em linguagens e frameworks que o CodeQL não cobre, como PHP, Shell, Terraform e Dockerfiles. É gratuito para repositórios públicos; os privados precisam do GitHub Code Security ou do Advanced Security, e nenhuma licença do Copilot é necessária. Suas descobertas são consultivas e não podem bloquear merges.

O que isso significa se você está escolhendo uma ferramenta de revisão

Se você quer um segundo revisor para bugs e lógica, o Claude Code Review cobre mais terreno. Teste-o em alguns repositórios com as revisões configuradas para rodar uma vez ou sob demanda, e só depois decida sobre "após cada push", o que multiplica o custo.

Se sua principal preocupação é segurança e você já paga pelos produtos de segurança do GitHub, o AI Scan vem incluído no que você já tem. Equipes que já usam o GitHub Copilot podem avaliar ambos: Claude Code vs GitHub Copilot.
