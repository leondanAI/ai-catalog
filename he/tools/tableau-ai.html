אודות Tableau AI

Tableau Agent הוא שכבת ה-AI הגנרטיבי של Salesforce בתוך Tableau. מתארים במילים פשוטות מה רוצים, והוא מסייע לבנות חישובים, להכין נתונים, להציע ויזואליזציות ולהסביר מה קורה בתרשים, במקום להצריך ניווט ידני בתפריטים.

המוצר נקרא בעבר Einstein Copilot for Tableau ועבר מיתוג מחדש ל-Tableau Agent. דפי התמחור של הספק מציגים כיום את Tableau Agent כפיצ'ר בתוך Tableau Authoring, Prep, Catalog, Dashboards ו-Pulse במסגרת מהדורת Tableau Cloud+, וכן במסגרת חבילת Tableau+ הרחבה יותר ובפלטפורמת Tableau Next העצמאית. מהדורות Tableau Server Standard ו-Enterprise כוללות את Tableau Agent עבור Authoring ו-Prep בלבד. Tableau Cloud Standard ו-Tableau Cloud Enterprise, הדרגים הנפוצים ביותר של Tableau Cloud, אינם כוללים את Tableau Agent.

היכולות מתמקדות בכתיבה בשפה טבעית: בקשת חישוב, תרשים או הסבר על ויזואליזציה, והאג'נט מנסח אותם עבורך. הוא חלק מהדחיפה הרחבה יותר של Salesforce לניתוח נתונים אוטונומי (agentic), הכוללת גם את Tableau Next, פלטפורמה נפרדת הבנויה על גבי Agentforce 360 Platform של Salesforce.

התמחור מדורג וחלקו מבוסס הצעת מחיר בלבד. Tableau Cloud Standard, בחיוב שנתי, עולה 75$ למשתמש לחודש עבור Creator, 42$ עבור Explorer ו-15$ עבור Viewer; Tableau Cloud Enterprise, גם הוא בחיוב שנתי, עולה 115$, 70$ ו-35$ בהתאמה — אף אחד מהדרגים אינו כולל את Tableau Agent. כדי לקבל את Tableau Agent בענן נדרשת מהדורת Tableau Cloud+ או חבילת Tableau+, שתיהן מוצרים מבוססי פנייה למכירות וחוזה שנתי ללא מחיר פומבי למשתמש. Tableau Next, הנמכר בנפרד, מתחיל ב-40$ למשתמש לחודש בחיוב שנתי וכולל את Tableau Agent. Tableau Server Standard מתחיל ב-15$ למשתמש לחודש ו-Enterprise ב-35$ למשתמש לחודש, שניהם בחיוב שנתי, וכוללים את Tableau Agent עבור Authoring ו-Prep. מוצעת גרסת ניסיון חינמית של Tableau Cloud, אם כי אורכה והאם נדרש כרטיס אשראי אינם מצוינים בדפי התמחור של הספק. קיימת גם Tableau Desktop Free Edition לכתיבת קבצים מקומית, אך ללא פיצ'רי AI.

המגבלות העיקריות הן ש-Tableau Agent אינו מוצר עצמאי במחיר אחיד: הוא מגיע ארוז בתוך מהדורות ספציפיות (Cloud+, Tableau+, Tableau Next, או Server Standard/Enterprise), חבילות הענן היקרות ביותר מתומחרות רק באמצעות הצעת מחיר, והדרגים הפשוטים והנפוצים ביותר של Tableau Cloud אינם כוללים אותו כלל.

ההיגיון במוצר מתאים לצוותים שכבר משקיעים ב-Tableau או במערכת האקולוגית הרחבה יותר של Salesforce, המעוניינים בכתיבה בשפה טבעית ובניתוח נתונים עצמאי, ומוכנים לתקצב את המהדורה הספציפית הכוללת את Tableau Agent.

שאלות נפוצות

כמה עולה Tableau?
Tableau Cloud Standard, בחיוב שנתי, עולה 75$ למשתמש לחודש עבור Creator, 42$ עבור Explorer ו-15$ עבור Viewer. Tableau Cloud Enterprise, גם הוא בחיוב שנתי, עולה 115$ עבור Creator, 70$ עבור Explorer ו-35$ עבור Viewer. Tableau Agent ופיצ'רי AI נוספים אינם כלולים בדרגים אלה ודורשים את Tableau Cloud+ Edition, חבילת Tableau+, או Tableau Next, המתומחרים בנפרד (Tableau Next מתחיל ב-40$ למשתמש לחודש בחיוב שנתי; Cloud+ ו-Tableau+ מבוססי הצעת מחיר בלבד).
מהו Tableau AI?
Tableau AI ממותג כיום כ-Tableau Agent, עוזר ה-AI הגנרטיבי של Salesforce עבור Tableau. הוא מספק שאילתות בשפה טבעית, סיוע בכתיבה מבוססת AI וסיוע בחישובים, וזמין דרך מהדורת Tableau Cloud+, חבילת Tableau+, Tableau Next, או Tableau Server Standard/Enterprise (עבור Authoring ו-Prep).
