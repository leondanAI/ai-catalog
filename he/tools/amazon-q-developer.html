Amazon Q Developer כבר לא זמין

Amazon Q Developer הופסק או הוחלף, ולכן הסרנו אותו מהקטלוג של AItoolFit. הכלים האלה מבצעים את אותן משימות וממשיכים להתפתח:

GitHub Copilot Freemium
קידוד בינה מלאכותית ב-VS Code, סוכני ענן, בדיקת קוד, בחירת מודלים בין ספקים

GitHub Copilot הוא עוזר קידוד אגנטי, רב-מודלי, שחורג מעבר להשלמה אוטומטית ומציע צ'אט, מצב סוכן, סוכני ענן, בדיקת קוד וממשק שורת פקודה (CLI), עם מודלים זמינים מספקים כולל Anthropic, OpenAI, Google, xAI, Microsoft ו-Moonshot. השירות מחייב שימוש דרך GitHub AI Credits, עם מסלולים הנעים ממסלול חינמי ועד תוכניות ליחידים וארגונים.

Cursor Freemium
IDE מבוסס AI, תכנות אגנטי, ריפוזיטוריז מרובים, בדיקת PR, סוכנים מקבילים

Cursor הוא עורך קוד מבוסס AI שנבנה על VS Code עם תכנות אגנטי, תמיכה במספר ריפוזיטוריז, סוכנים מקבילים ובדיקת PR אוטומטית. לקוחות חדשים נרשמים כעת דרך The X Subscription, חבילה המשלבת את Cursor עם Grok מבית xAI ו-X Premium, בעוד שמודלים חיצוניים אחרים מחויבים בנפרד לפי מחיר ה-API.

Cline Freemium
סוכן קידוד אוטונומי עם אישור שלב-אחר-שלב, זמין ב-VS Code, JetBrains, CLI ואפליקציית שולחן עבודה

סוכן קידוד אוטונומי בקוד פתוח, זמין כתוסף ל-VS Code, פלאגין ל-JetBrains, כלי CLI ואפליקציית שולחן עבודה נייטיבית, שיוצר קבצים, מריץ פקודות טרמינל ושולט בדפדפנים — הכול באישור המשתמש שלב אחר שלב. עובד עם כל LLM באמצעות מפתח API משלך או ספק ההסקה של Cline עצמו.
