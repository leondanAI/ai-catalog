Notion Developer Platform 3.5: Workers Runtime, סנכרון דאטהבייס חד-כיווני, Webhooks דו-כיווניים וממשקי Agent חדשים

כלים May 13, 2026·Notion Blog

Notion השיקה את Developer Platform 3.5 ב-13 במאי 2026 — העדכון המשמעותי ביותר המיועד למפתחים בתולדות החברה. המהדורה מציגה כמה יכולות חדשות ההופכות את Notion ממרחב עבודה לניהול ידע לפלטפורמה הניתנת לתכנות עם הרצת בינה מלאכותית אגנטית.

סביבת Workers

סביבת Workers היא סביבת ריצה מתארחת של Notion לקוד מותאם אישית, הנפרסת באמצעות ה-Notion CLI החדש ורצה בסביבה מבודדת (sandboxed) בתוך Notion. לוגיקה — אוטומציות, טרנספורמציות של נתונים, אינטגרציות — חיה לצד התוכן עצמו במקום בשירותים חיצוניים. מסד נתונים ב-Notion יכול כעת להפעיל פונקציה, לעבד את הנתונים, לקרוא ל-API חיצוני, ולכתוב בחזרה את התוצאות — הכול בתוך סביבת Notion, ללא צורך בניתוב דרך Zapier, Make, או תשתית backend מותאמת אישית. השימוש ב-Workers חינמי בתקופת הבטא, כאשר תמחור מבוסס על קרדיטים של Notion ייכנס לתוקף החל מ-11 באוגוסט 2026.

Database Sync

Database Sync, הנמצא כעת בבטא, מאפשר ל-Workers למשוך נתונים מממשקי API חיצוניים אל תוך מסדי נתונים ב-Notion — למשל, ייבוא כרטיסי פנייה (tickets) מ-Zendesk או רשומות מ-Salesforce ישירות לתוך Notion. החיבור הוא חד-כיווני: נתונים חיצוניים זורמים אל תוך Notion, ומעניקים לצוותים תצוגה חיה ומתעדכנת ברציפות של מידע שבעבר דרש ייבוא ידני או אוטומציה חד-פעמית.

Bidirectional Webhooks וממשקי agent חדשים

Bidirectional Webhooks מרחיבים את מודל האירועים בשני הכיוונים: Notion יכולה לקבל webhooks נכנסים משירותים חיצוניים כדי להפעיל תהליכי עבודה, ולשלוח webhooks יוצאים כאשר תוכן ב-Notion משתנה. המהדורה מציגה גם יכולות agent חדשות: External Agents API (בשלב אלפא) לחיבור agents חיצוניים ל-Notion, כלי agent מותאמים אישית הבנויים כ-Workers (בבטא), וכן Notion Agent SDK (בשלב אלפא) לבניית agents הפועלים על נתונים מובנים של Notion.

למה זה חשוב

Developer Platform 3.5 ממצבת את Notion כפלטפורמה שבה קוד מותאם אישית ו-agents פועלים על נתונים מובנים ומקושרים זה לזה, ולא רק על מסמכים. עבור צוותים המשתמשים כבר ב-Notion כמרכז התפעולי שלהם, Workers ו-Database Sync פותחים יכולות אוטומציה ואינטגרציה שבעבר דרשו עבודת הנדסה ייעודית. עבור בוני בינה מלאכותית, ממשקי ה-agent וה-SDK החדשים הופכים את מסדי הנתונים של Notion לתשתית לבניית תהליכי עבודה אוטונומיים מבוססי agent.
