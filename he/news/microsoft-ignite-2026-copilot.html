Microsoft Ignite 2026: Word, Excel ו-PowerPoint עוברים אל תוך Copilot, ו-Copilot Code ו-Autopilot נשארים בגישה מוקדמת

כלים Nov 17, 2026·Microsoft Book of News

בכנס Microsoft Ignite 2026 ב-17 בנובמבר הראתה Microsoft כיצד עוזר העבודה שלה הופך מחלון צ׳אט למקום שבו כותבים מסמכים, מאצילים משימות ואפילו בונים אפליקציות קטנות. חלק מזה כבר זמין, אבל הרבה עדיין בתוכנית הגישה המוקדמת Frontier. הנה מה שמקבלים משתמשי Microsoft Copilot בעבודה.

זמין כבר עכשיו

Home. מסך הפתיחה החדש של אפליקציית Copilot מאחד את Chat ו-Cowork עם תיבת קלט אחת המופעלת על ידי Auto, שבוחר את המודל לכל משימה. הוא זמין לכלל המשתמשים ומופץ ברחבי העולם. כשבקשה מורכבת, Auto יכול כעת להציע להעביר אותה מ-Chat ל-Cowork, וההקשר עובר יחד איתה.

Word, Excel ו-PowerPoint בתוך Copilot. Office in Copilot זמין לכלל המשתמשים: אפשר לעבור ישירות משיחה למסמך, לגיליון אלקטרוני או למצגת, לערוך אותם ולעבוד עליהם במשותף כרגיל, ולפתוח את האפליקציה המלאה כשצריך. הקבצים נשמרים ב-OneDrive ושומרים על ההרשאות ותוויות הרגישות של Microsoft 365. לדברי Microsoft, הדבר כלול ברישיון המנוי של Copilot, ללא חיוב נוסף לפי שימוש.

Copilot Managed Runtime, שכבת האירוח לאפליקציות שנבנו ב-Copilot Code, Copilot Cowork וב-Copilot Studio, זמינה גם היא לכלל המשתמשים.

בינתיים רק בתוכנית Frontier

Copilot Code מאפשר לכל אחד לתאר במילים פשוטות לוח מחוונים, כלי מעקב או אפליקציה, ו-Copilot בונה אותם, באמצעות אותה טכנולוגיה אייג׳נטית של GitHub Copilot. הוא זמין ב-Frontier ב-Windows, בדפדפן, ב-iOS וב-Android, ולדברי Microsoft יהיה זמין לכלל המשתמשים בדצמבר. סביבת ה-sandbox המקומית פועלת ב-Windows; macOS "בקרוב".

Autopilot הוא סוכן אישי הפועל לאורך זמן, עם זהות, זיכרון וכלים משלו. הוא יכול לעקוב אחר שרשורים ולבצע עבודה חוזרת בלי הנחיה חדשה, ועמיתים יכולים לתייג אותו עם @ ב-Teams. מחלקת ה-IT יכולה לחסום אותו בכל עת. ההפצה ללקוחות Frontier החלה ב-17 בנובמבר.

Copilot Workspaces, היורש של Copilot Notebooks, הוא מרחב צוות משותף שבו Copilot עוקב אחר מה שהשתנה. הוא זמין ב-Frontier; הוספת ה-Autopilot שלכם למרחב עבודה תגיע "בקרוב".

Today, תדריך יומי על פני הדואר, היומן ו-Teams, נמצא בתצוגה מקדימה פרטית. ה-Today Brief של הבוקר כלול ברישיון Microsoft 365 Copilot, ואילו ה-Today Feed לאורך כל היום דורש קרדיטים של Copilot.

Copilot ב-Windows: בתצוגה מקדימה

Copilot ב-Windows יוכל למצוא, לארגן, להעביר, להעתיק או לשנות שם של קבצים במחשב לפי בקשה בשפה פשוטה, לעזור לאבחן בעיות במחשב ולהיפתח מתוך החיפוש החדש של Windows בשורת המשימות, אם תבחרו בכך. שלוש היכולות נמצאות בתצוגה מקדימה וממשיכות את התוכנית מאירוע Windows באוקטובר.

מה זה אומר אם אתם משתמשים ב-Copilot בעבודה

אם החברה שלכם כבר משלמת על Microsoft 365 Copilot, כדאי לנסות עכשיו את תהליך העבודה של Office in Copilot: הוא לא עולה דבר נוסף ושומר את הקבצים בתוך ההרשאות הרגילות. Copilot Code ו-Autopilot עדיין אינם זמינים באופן רחב, אז אל תתכננו סביבם לפני דצמבר. לעוזר צ׳אט כללי מחוץ ל-Microsoft 365, ראו את המדריך שלנו Microsoft Copilot vs ChatGPT.
