GitHub Universe 2026: אפליקציית Copilot מהנפקת משימה עד מיזוג, ניתוב מודלים ב-Copilot Fusion ו-Copilot לכל לקוחות Enterprise

כלים Oct 28, 2026·GitHub

GitHub ניצלה את כנס Universe שנערך ב-28 באוקטובר כדי למצב מחדש את GitHub Copilot ממסייע קידוד למערכת להשלמת עבודה. ארבע הכרזות חשובות במיוחד לכל מי שבוחר כלי קידוד.

אפליקציית Copilot

אפליקציית שולחן עבודה חדשה, המוצעת כרגע להורדה למחשבי Mac עם שבבי Apple, שנבנתה כדי להעביר משימה מ-issue ועד merge. היא מחברת סוכנים וכלים בין פרויקטים ומכסה גם עבודה סביב הקוד, כגון כתיבת מפרטים וניתוח נתוני טלמטריה. בתוכה, Copilot projects, זמין החל מיום ההשקה, מריץ עבודת סוכנים על פני כמה מאגרי קוד (repositories) במקביל, עם מקום אחד למעקב אחר ההתקדמות. ניתן לעקוב ולהנחות סשן סוכן בענן מתוך האפליקציה, VS Code, ה-CLI או האינטרנט.

Copilot Fusion

Fusion הוא נתב מודלים (model router): בוחרים אותו בתפריט המודלים, ועבור כל בקשה הוא קובע אילו מודלים להשתמש בהם וכיצד, החל ממודל יחיד ועד כמה מודלים שעורכים טיוטה, מבקרים ומתקנים. הוא זמין באופן כללי ב-VS Code, ב-Copilot CLI, באפליקציית Copilot ובסביבות הפיתוח של JetBrains. Fusion Standard זמין בכל התוכניות, כולל Free; Fusion High דורש Pro+‏, Max‏, Business או Enterprise; Fusion Max דורש Max‏, Business או Enterprise. אין תשלום נפרד: משלמים קרדיטי AI עבור כל מודל שהוא מפעיל.

GitHub טוענת ש-Fusion Max השיג ציון בפער של שתי נקודות בלבד מ-Claude Opus 5.5 Max במדד Artificial Analysis Coding Agent Index, בחצי מהעלות וב-40% פחות זמן למשימה. זוהי טענה של GitHub עצמה.

סקירת קוד Max

סקירת הקוד של Copilot מקבלת רמה שלישית, המעמיקה ביותר, בשם Max, בתצוגה מקדימה ציבורית (public preview). היא משתמשת בכמה מודלים בעלי יכולת היסק גבוהה, ולפי התיעוד של GitHub העלות הממוצעת היא כ-10 דולר בקרדיטי AI לסקירה, לעומת כ-1.50 דולר לרמת ברירת המחדל Balanced ו-0.25 דולר ל-Lite.

Copilot כלול עבור GitHub Enterprise

לקוחות GitHub Enterprise יכולים כעת להשתמש בכל תכונות Copilot, כולל האפליקציה, סקירת קוד ואוטומציות, ללא רכישת מנוי Copilot נפרד. הם משלמים עבור קרדיטי ה-AI שבהם הם משתמשים. בשלב זה הדבר מתבצע דרך מחלקת המכירות של GitHub, עם הבטחה לאפשרות שירות-עצמי (self-serve) בעתיד, ולקוחות קיימים של Copilot Business ו-Enterprise יכולים לשמור על התוכניות הנוכחיות שלהם. עבור יחידים, Copilot מוצע במחיר של 10 דולר לחודש עבור Pro, 39 דולר עבור Pro+ ו-100 דולר עבור Max.

המשמעות עבור מי שבוחר סוכן קידוד

אם החברה שלכם כבר משלמת עבור GitHub Enterprise, כדאי לשאול את מנהל המערכת על אפשרות התשלום לפי קרדיטים לפני רכישת סוכן קידוד נפרד: ייתכן שתקבלו את Copilot ללא חוזה חדש לפי מושב (per-seat).

אם אתם משווים בין Copilot ל-Claude Code, Fusion וסקירת קוד Max מקרבים בין המוצרים, והעלות תלויה כעת בקרדיטים שבהם משתמשים ולא במספר המושבים. ראו Claude Code vs GitHub Copilot.
