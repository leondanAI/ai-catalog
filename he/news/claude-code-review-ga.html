Claude Code Review זמין כעת לכל המשתמשים בתוכניות Team ו-Enterprise, עם שלוש רמות: Quick, Standard ו-Deep

כלים Oct 15, 2026·Anthropic

Anthropic הוציאה את Code Review משלב התצוגה המוקדמת למחקר ב-15 באוקטובר. הכלי זמין כעת באופן כללי לארגונים בתוכניות Claude Team ו-Enterprise. Code Review הוא חלק מ-Claude Code: ברגע שמנהל מערכת מפעיל אותו, Claude בודק בקשות משיכה במאגרי ה-GitHub שלכם ומוסיף הערות על השורות שהוא מסמן.

איך זה עובד

מספר סוכנים קוראים את השינוי ואת הקוד שמסביבו במקביל, ומחפשים שגיאות לוגיות, פרצות אבטחה ומקרי קצה שבורים. שלב אימות בודק כל ממצא מול הקוד כדי לסנן תוצאות שגויות, והשאר מדורגים לפי חומרה. הבדיקה מפרסמת הערות מוטבעות בשורה, סיכום והרצת בדיקה (check run). היא לעולם לא מאשרת או חוסמת בקשת משיכה, כך שההחלטה לבצע מיזוג (merge) נשארת בידי הצוות. כברירת מחדל הכלי מחפש באגים שעלולים לשבש את הסביבה הפרודקטיבית, לא בעיות עיצוב או חוסר בבדיקות, וצוותים יכולים לכוון אותו באמצעות קובץ REVIEW.md.

מה השתנה עם הזמינות הכללית

מהירות: לפי Anthropic, רוב הבדיקות מסתיימות כעת תוך 6 עד 10 דקות, מהירות פי שלושה בערך לעומת כ-20 דקות בתקופת התצוגה המוקדמת.
רמות בדיקה: Quick (המהירה והזולה ביותר), Standard (ברירת המחדל) או Deep (היסודית ביותר, האיטית והיקרה ביותר), שניתן להגדיר עבור הארגון כולו, ובמידת הצורך, עבור כל מאגר קוד בנפרד.
מתי זה רץ: כל מאגר קוד יכול לבצע בדיקה פעם אחת כשנפתחת בקשת משיכה, לאחר כל דחיפה (push), או רק כשמישהו כותב בהערה "@claude review".

מחיר וזמינות

אין מחיר קבוע לכל בדיקה. החיוב על הבדיקות מתבצע לפי שימוש בטוקנים דרך קרדיטים לשימוש, בנפרד מהשימוש הכלול בתוכנית, והעלות תלויה ברמת הבדיקה, בגודל השינוי ובתדירות הרצת הבדיקות. מנהלי מערכת יכולים לקבוע מגבלת הוצאה חודשית. ארגוני Enterprise זכאים יכולים לקבל לפחות 10,000$ בקרדיטים ל-Code Review עד 15 בינואר 2027; הקרדיטים פגים תוקף 30 יום לאחר קבלתם. Code Review עובד עם GitHub, כולל GitHub Enterprise Server, ואינו זמין לארגונים עם הגדרת Zero Data Retention או תצורת HIPAA.

האופציה של GitHub, באותו היום

גם ב-15 באוקטובר, GitHub הפכה את AI Scan עבור בקשות משיכה לזמין באופן כללי. מדובר בכלי צר יותר: הוא מחפש פרצות אבטחה בשינויים בבקשות משיכה, בשפות ובמסגרות עבודה שאינן מכוסות על ידי CodeQL, כמו PHP, Shell, Terraform וקובצי Dockerfile. הכלי חינמי עבור מאגרי קוד ציבוריים; מאגרים פרטיים דורשים GitHub Code Security או Advanced Security, ואינו דורש רישיון Copilot. הממצאים שלו הם בבחינת המלצה בלבד ואינם יכולים לחסום מיזוגים.

מה המשמעות עבורכם אם אתם בוחרים כלי בדיקה

אם אתם רוצים בודק נוסף לבאגים וללוגיקה, Claude Code Review מכסה שטח רחב יותר. מומלץ להריץ אותו בתור פיילוט על מספר מאגרי קוד עם בדיקות המוגדרות לרוץ פעם אחת או לפי דרישה, ורק אז להחליט על אפשרות "לאחר כל דחיפה", שמכפילה את העלות.

אם הדאגה העיקרית שלכם היא אבטחה ואתם כבר משלמים עבור מוצרי האבטחה של GitHub, AI Scan מגיע כחלק ממה שכבר יש לכם. צוותים שכבר משתמשים ב-GitHub Copilot יכולים לשקול בין השניים: Claude Code vs GitHub Copilot.
