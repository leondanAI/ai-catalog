GitHub Copilot מבטלת חיוב לפי בקשות — מערכת קרדיטים ל-AI עולה לאוויר ב-1 ביוני

עסקים Jun 1, 2026·GitHub Blog

עוזר הקידוד מבוסס ה-AI של GitHub עבר בכל תוכניותיו למודל חיוב מבוסס שימוש ב-1 ביוני, 2026, והחליף בכך את מערכת החיוב הקבועה הקודמת שהתבססה על מספר בקשות. השינוי מציג מטבע חדש — GitHub AI Credits — והופך את העלות של כל אינטראקציה עם Copilot למשתנה, בהתאם למודל שבו נעשה שימוש ולכמות הטוקנים שנצרכה.

איך עובדים ה-AI Credits

קרדיט GitHub AI אחד שווה ל-0.01$. כל אינטראקציה עם Copilot מנוכה מיתרת קרדיטים חודשית, כאשר העלות נקבעת לפי דרגת המודל ומספר הטוקנים. מודלים קלים המשמשים להשלמה אוטומטית עולים פחות קרדיטים; מודלים מתקדמים המשמשים למשימות הסקה מורכבות עולים יותר. כל התוכניות בתשלום כוללות הקצאת קרדיטים חודשית, עם אפשרות לרכישת קרדיטים נוספים.

הקצאת קרדיטים לפי תוכנית

Pro (10$ לחודש): כולל 1,500 קרדיטים. Pro+ (39$ לחודש): כולל 7,000 קרדיטים. Max (100$ לחודש): כולל 20,000 קרדיטים, המורכבים מ-10,000 קרדיטים בסיסיים ו-10,000 קרדיטים גמישים. תוכניות Business כוללות 1,900 קרדיטים למשתמש, ותוכניות Enterprise כוללות 3,900 קרדיטים למשתמש.

את מה זה מחליף

המערכת הקודמת גבתה תשלום קבוע עבור כל "בקשת פרימיום", ללא קשר למודל או למספר הטוקנים. המערכת החדשה מבטלת כליל את הגדרת בקשת הפרימיום. GitHub טוענת שחיוב מבוסס שימוש משקף טוב יותר את עלויות החישוב בפועל ומאפשר למשתמשים לשלב מודלים שונים בתוך אותה הפעלה. מבקרים מציינים שמשתמשים כבדים במודלי פרימיום עלולים להיתקל בחשבונות חודשיים גבוהים מהצפוי אם השימוש לא ייעקב אחריו.

למה זה חשוב

GitHub Copilot הוא עוזר הקידוד מבוסס ה-AI הגדול ביותר מבחינת משתמשים פעילים. שינוי החיוב משפיע על מיליוני מפתחים ועשרות אלפי ארגונים. המעבר לקרדיטים משקף את תמחור הטוקנים הנהוג אצל OpenAI ו-Anthropic — ומסמן שהתמחור הקבוע של מוצרי AI מפנה את מקומו לכלכלת תשתית מדודה בכל רחבי התעשייה.
