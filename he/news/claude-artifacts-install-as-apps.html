Claude יכול עכשיו להפוך את הארטיפקטים שלו לאפליקציות שולחן עבודה ל-Mac ול-Windows

כלים Nov 24, 2026·Claude Help Center

ב-24 בנובמבר הוסיפה Anthropic שלוש יכולות ל-Claude. הבולטת שבהן: ארטיפקט ש-Claude בונה עבורכם, כמו טיימר, לוח מחוונים קטן או כלי לשינוי שמות של קבצים, אפשר עכשיו להתקין כאפליקציה במחשב Mac או Windows.

ארטיפקטים כאפליקציות

ארטיפקט מותקן מקבל חלון ואייקון משלו ונפתח כמו כל תוכנה אחרת: ב-Mac מתיקיית Claude Apps, דרך Spotlight או מה-Dock, וב-Windows מתפריט התחל או מקיצור דרך בשולחן העבודה. זה נשאר אותו ארטיפקט, כך שכאשר אתם או עורך אחר משנים אותו ב-Claude, גם האפליקציה מתעדכנת. כדי לפתוח אותה צריך חיבור לאינטרנט וכניסה ל-Claude Desktop.

כדי להתקין, פתחו את הארטיפקט ב-Claude Desktop, פתחו את תפריט הכותרת שלו (או לחצו עליו בלחצן הימני) ובחרו Install as app. בין הדוגמאות של Anthropic למה שאפשר לבקש: טיימר Pomodoro בשורת התפריטים, אפליקציה ל-Mac שמזכירה להתמתח כל שעה, ואפליקציה ל-Windows שמשנה את שמות התמונות בתיקייה לפי תאריך.

היכולת זמינה בבטא במסלולים Free, Pro, Max, Ultra, Team ו-Enterprise, ודורשת Claude ל-Mac או ל-Windows בגרסה 6.28899.0 ומעלה. במסלולי Team היא מופעלת כברירת מחדל; במסלולי Enterprise בעלים צריך להפעיל אותה.

הרשאות

אפליקציה יכולה להשתמש ב-Claude ובמחברים שלכם בדיוק כמו הארטיפקט. כל דבר מעבר לכך דורש ״אישור״ נפרד: התראות, קיצורי מקלדת גלובליים, ריחוף מעל חלונות אחרים, אייקון בשורת התפריטים או במגש המערכת, והדרגה הגבוהה ביותר, גישה מלאה למחשב, שמאפשרת לאפליקציה להפעיל תוכנות ולקרוא, לשנות או למחוק קבצים. כל אישור חל על גרסה אחת של האפליקציה, ולכן אחרי כל עריכה Claude שואל שוב.

Anthropic מבהירה במפורש שהיא אינה בודקת אפליקציות לפני ההתקנה, וממליצה לתת גישה מלאה רק אם אתם סומכים על כל מי שכתב את האפליקציה. Claude מציג אזהרה כשאפליקציה מגיעה מחוץ לארגון שלכם או כשאי אפשר לאמת את היוצר שלה, ובמסלולי Team הגישה המלאה נשארת כבויה עד שמנהל מפעיל אותה.

עוד שני עדכונים

הסיכום החודשי (Reflect, בהגדרות) יצא מבטא במסלולים Free, Pro, Max ו-Ultra, בדפדפן, במחשב ובנייד. הסיכומים יכולים לכלול עכשיו גם את הסשנים שלכם ב-Claude Code ומשימות Cowork בענן, ואפשר למחוק סיכומים שמורים.

קבצים ומחברים: Claude יכול עכשיו לשלוח קובץ לאפליקציה שחיברתם, או לשמור קובץ שהאפליקציה מציעה. היכולת נפרסת בהדרגה בבטא במסלולים Pro, Max ו-Ultra, ובמסלולי Team ו-Enterprise כשבעלים מפעיל אותה.

כמה ימים קודם לכן, ב-20 בנובמבר, החלה Anthropic גם להשיק עיצוב מחודש לאפליקציית Claude לנייד (תחילה ב-iOS 26 ומעלה), ופתחה את computer use בבטא למסלולי Team ו-Enterprise.

למי זה חשוב

ארטיפקטים שאפשר להתקין מקרבים את Claude לכלי לבניית כלים אישיים קטנים בלי לכתוב קוד בעצמכם, נישה שבה אנשים פונים בדרך כלל לבוני אפליקציות כמו Lovable או Replit. ההבדל הוא שאפליקציה של Claude רצה על המחשב שלכם ואפשר לתת לה גישה אליו, ולכן כדאי לקרוא בעיון את בקשות ההרשאה. מתלבטים בין עוזרים? ראו ChatGPT מול Claude.
