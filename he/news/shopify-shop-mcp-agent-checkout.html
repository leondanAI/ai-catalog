Shopify משיקה את Shop MCP: כל סוכן AI יכול לחפש מעל מיליארד מוצרים ולבצע תשלום עם Shop Pay

כלים Oct 13, 2026·Shopify

Shopify הכריזה על Shop MCP ב-13 באוקטובר. מדובר בחיבור MCP יחיד שמעניק לסוכן AI או לאפליקציה שלושה יכולות בבת אחת: חיפוש ב-Shopify Catalog, שמכיל מעל מיליארד מוצרים, בניית עגלות קנייה, והשלמת תשלום באמצעות Shop Pay. MCP (Model Context Protocol) הוא הסטנדרט הפתוח שבו משתמשים עוזרי AI כדי להתחבר לכלים חיצוניים.

איך זה עובד

השרת הוא נקודת קצה מרוחקת בכתובת mcp.shop.com, ו-Shopify מציינת שכל לקוח MCP יכול להתחבר אליו, וכך גם קוד עצמאי. תיאור יכולות (skill description) שסוכנים יכולים לקרוא בעצמם פורסם בכתובת mcp.shop.com/skill.md. השרת חושף 17 כלים, כולל חיפוש ואיתור מוצרים, כלי עגלת קנייה ותשלום, סטטוס תשלום, וחיפוש הזמנות עם מעקב משלוח עבור קונים מחוברים.

החיפוש אינו דורש מפתח API. גם עגלות קנייה ותשלום פועלים ללא התחברות. כדי לשלם באמצעות Shop Pay, הקונה מתחבר עם Shop, מה שמאפשר לתהליך התשלום להשתמש בכתובות השמורות שלו וב-Shop Pay. לפי Shopify, לקוחות MCP כגון Claude ו-ChatGPT מטפלים בהתחברות הזו, וקוד מותאם אישית יכול להשתמש בתהליך device flow.

מי לוחץ על "קנייה"

כברירת מחדל, הקונה משלם בעמוד התשלום של הסוחר עצמו דרך קישור שהסוכן מעביר. קונה מחובר יכול לחלופין לתת לסוכן להשלים את הרכישה, אך רק לאחר שאישר את הסכום הכולל ואמצעי תשלום. כל תהליך תשלום שייך לסוחר אחד, כך שפריטים משלוש חנויות שונות דורשים שלושה תהליכי תשלום נפרדים.

עבור הסוחרים, הזמנות שבוצעו דרך סוכן מופיעות בממשק הניהול של Shopify כמו כל הזמנה אחרת. בשלב ההשקה אין webhooks, כך שעל מפתחים לבצע polling (בדיקות חוזרות) כדי לעקוב אחר סטטוס התשלום. אינטגרציות קיימות של Catalog API ממשיכות לעבוד ללא שינויים. Shopify גם פרסמה כלי שורת פקודה, @shopify/shop, לחיפוש מהטרמינל.

מה המשמעות עבורכם אם אתם קונים או בונים עם סוכני AI

אם אתם משתמשים בעוזר AI למשימות יומיומיות, קנייה הופכת להיות אחת מהן. Claude ו-ChatGPT הם הלקוחות ש-Shopify מציינת כמי שמטפלים בהתחברות ל-Shop. לפני שתתנו לסוכן להשלים רכישה, בדקו את הסכום הכולל, החנות ואמצעי התשלום שהוא מציג לכם, שכן אישור זה הוא אמצעי ההגנה המובנה בתהליך.

אם אתם מתלבטים באיזה עוזר להשתמש, תמיכה בחיבורים (connectors) היא כעת גורם ממשי לצד איכות התשובות. ראו השוואה בין השניים ב-ChatGPT vs Claude.

אם אתם בונים סוכנים, Shop MCP היא דרך קלה להוסיף חיפוש מוצרים: אין צורך במפתח או באינטגרציה עם סוחר כדי להתחיל, ואפשר להוסיף את יכולת התשלום מאוחר יותר.
