Cursor בונה ומארח כעת אפליקציות שאפשר לשתף, ומאפשר לדבר עם הסוכנים שלו בקול

כלים Nov 6, 2026·Cursor Changelog

Cursor הוסיפה שתי תכונות לעורך הקוד מבוסס הבינה המלאכותית שלה בשבוע הראשון של נובמבר. אחת מקרבת אותו לבוני אפליקציות כמו Lovable ו-Replit; השנייה מאפשרת לדבר עם סוכני תכנות במקום להקליד.

Live Apps

Live Apps, שיצאה ב-5 בנובמבר, מאפשרת לתאר אפליקציה לסוכן בענן ולקבל אותה בנויה, מחוברת למסד נתונים Postgres במידת הצורך, עם התחברות דרך Cursor SSO ופרוסה על אחסון. לאחר מכן משתפים אותה באמצעות קישור: עם אנשים מסוימים, קבוצות או כל הצוות, תמיד מאחורי התחברות ל-Cursor. בתוכניות אישיות אפשר גם לשתף אפליקציות באופן ציבורי.

לפני שמשהו עולה לאוויר, Cursor מריצה בדיקות אוטומטיות ובדיקות של סוכנים לאיתור בעיות כמו סודות שנשארו בקובצי האפליקציה או פרטי גישה חשופים. אם בדיקה נכשלת, הסוכן מדווח מה צריך לתקן, ושום דבר אינו מתפרסם עד שהבדיקות עוברות ואתם מאשרים. מנהלי צוות יכולים לראות כל אפליקציה, להוסיף כללי בדיקה משלהם ולהסיר אפליקציות מפרסום. Live Apps זמינה בכל התוכניות בתשלום שבהן סוכני ענן מופעלים. האפליקציות נפרסות ממאגרים ב-Cursor Origin או ב-GitHub; GitLab וספקים אחרים מופיעים כמי שיתווספו בקרוב.

צ׳אט קולי עם סוכנים

ב-6 בנובמבר הוסיפה Cursor צ׳אט קולי דו-כיווני עם סוכנים ב-Agents Window, ב-IDE, באתר וב-Cursor ל-iOS, שם המשפט "Hey Siri, call Cursor" פותח שיחה עם סוכן חדש. אפשר להמשיך לדבר בזמן שהסוכן עובד, לשאול מה השתנה ב-diff או לבדוק את מצב ההרצה, והסוכן מוסר עדכוני התקדמות קוליים קצרים. הצ׳אט הקולי פועל על Grok Voice; כאשר Privacy Mode מופעל, הוא פועל ללא שמירת נתונים. תכונת ההכתבה הקודמת נשארת כאפשרות נפרדת.

מה זה אומר אם אתם בוחרים כלי לתכנות

כלים פנימיים בלי אחסון נפרד. אם אתם צריכים לוח בקרה או טופס מהיר לצוות, Cursor יכולה כעת לבנות, לבדוק ולארח אותו במקום אחד, אבל השיתוף קשור לחשבונות Cursor, אלא אם אתם בתוכנית אישית.

השוו לפני שאתם עוברים. עיינו בעמוד Cursor שלנו, בהשוואה Cursor מול GitHub Copilot וברשימות כלי בינה מלאכותית לתכנות ובוני אפליקציות ללא קוד.
