Cursor Freemium
KI-IDE, agentisches Coding, Multi-Repo, PR-Review, parallele Agenten

Cursor ist ein KI-first Code-Editor, der auf VS Code basiert und agentisches Coding, Multi-Repo-Unterstützung, parallele Agenten sowie automatisiertes PR-Review bietet. Die hauseigene Modellpalette umfasst nun Grok 4.7, Grok 4.6, Grok 4.5 und Composer 2.5, neben unterstützten Modellen von Drittanbietern.

GitHub Copilot Freemium
KI-Coding in VS Code, Cloud Agents, Code Review, Modellauswahl über Anbieter hinweg

GitHub Copilot ist ein agentischer, multi-modellfähiger Coding-Assistent, der weit über Autovervollständigung hinausgeht und Chat, einen Agentenmodus, Cloud Agents, Code Review sowie eine CLI bietet, mit Modellen von Anbietern wie Anthropic, OpenAI, Google, xAI, Microsoft und Moonshot. Die Nutzung wird über GitHub AI Credits abgerechnet, mit Stufen von einem kostenlosen Plan bis zu Einzelpersonen- und Organisationsplänen.
