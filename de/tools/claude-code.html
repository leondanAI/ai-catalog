Über Claude Code

Claude Code ist Anthropics agentisches Entwicklungswerkzeug. Es liest deine Codebasis, bearbeitet Dateien, führt Befehle aus und kann eine Aufgabe von einer Anfrage in natürlicher Sprache bis zur fertigen Änderung durchziehen, statt nur Vervollständigungen im Editor vorzuschlagen.

Die aktuelle Version ist CLI v2.1.x (v2.1.185-v2.1.193, Ende Juni 2026). Seit dem 28. Mai 2026 ist Claude Opus 4.8 das Standardmodell - Anthropics stärkstes Modell für Computer Use und Browser-Agenten, das standardmäßig mit hohem Aufwand arbeitet (mehr geht mit /effort xhigh). Der Fast-Modus läuft nun ebenfalls auf Opus 4.8, zu $10/$50 pro Million Tokens und damit rund 3-mal günstiger als die abgelösten Modelle.

Über das Terminal hinaus deckt Claude Code Web und Mobil ab. Zu den jüngsten Neuerungen zählen 'dynamische Workflows', die Dutzende bis Hunderte Subagenten orchestrieren, der erweiterte Auto-Modus (jetzt im Pro-Plan sowie auf Bedrock, Google Cloud und Microsoft Foundry), Computer Use in der CLI, die Cloud-Bug-Suche /ultrareview, Artifacts (Beta), geplante Cloud-Agenten (Routines), native Windows-Unterstützung ohne Git Bash, /code-review und Subagenten im Hintergrund.

Preise: Der kostenlose Tarif ($0) enthält Claude Code nicht. Enthalten ist es in Pro ($17/Monat jährlich oder $20/Monat monatlich), Max 5x (ab $100/Monat), Max 20x ($200/Monat), Team Premium ($100/Platz/Monat jährlich, $125 monatlich, mindestens 5 Plätze) und Enterprise (Platz plus Nutzung zu API-Tarifen ab $20/Platz). Team Standard kostet $20/Platz/Monat jährlich ($25 monatlich). Der API-Zugang wird separat berechnet: Einführungspreis $2/$10 pro Million Tokens bis 31. August 2026, danach $3/$15; der Opus-4.8-Fast-Modus liegt bei $10/$50.

Die Grenzen sollte man kennen. Es gibt keine kostenlose Nutzung, Nutzungslimits gelten auch in bezahlten Plänen (am 6. Mai 2026 hat Anthropic die Limits verdoppelt und eine nutzungsbasierte Überschreitung mit Ausgabenlimit ergänzt), und die API-Nutzung kann bei großen agentischen Läufen teuer werden. Läufe mit hohem Aufwand können langsam sein und Tokens schnell verbrauchen.

Es eignet sich für professionelle Entwickler und Teams, die einen Agenten wollen, der Code tatsächlich bearbeitet und ausliefert - besonders für alle, die bereits einen Pro-, Max- oder Team-Plan haben und Coding ohne separate API-Rechnung inklusive wünschen.

Häufig gestellte Fragen

Was ist Claude Code?
Claude Code ist Anthropics offizielles CLI-Tool für Software-Engineering. Es läuft im Terminal, liest die Codebasis, schreibt Code, führt Befehle aus, behebt Bugs und schließt Multi-Datei-Aufgaben als autonomer Agent ab.
Was kostet Claude Code?
Enthalten in Claude Pro ($20/Monat), Max ($100/Monat), Team und Enterprise. Die Nutzung wird nach API-Tokens gemessen, die während agentischer Aufgaben verbraucht werden.
Wie unterscheidet sich Claude Code von Cursor?
Claude Code läuft im Terminal — ohne GUI. Es ist für Entwickler gedacht, die CLI-Workflows bevorzugen. Cursor ist eine vollständige IDE mit visueller Oberfläche auf VS Code-Basis.
Was kann Claude Code autonom tun?
Dateien lesen und bearbeiten, Shell-Befehle ausführen, Tests ausführen, die Codebasis durchsuchen, git verwalten und mehrstufige Engineering-Aufgaben mit minimalem Prompting abschließen.
