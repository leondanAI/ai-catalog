Amazon Q Developer wurde eingestellt oder ersetzt, deshalb haben wir es aus dem AItoolFit-Katalog entfernt. Diese Tools decken dieselben Aufgaben ab und werden aktiv weiterentwickelt:

GitHub Copilot Freemium
KI-gestütztes Programmieren in VS Code, Cloud-Agents, Code-Reviews, Modellauswahl über mehrere Anbieter hinweg

GitHub Copilot ist ein agentischer, multimodaler Coding-Assistent, der weit über Autovervollständigung hinausgeht und Chat, einen Agentenmodus, Cloud-Agents, Code-Review und eine CLI bietet, mit Modellen von Anbietern wie Anthropic, OpenAI, Google, xAI, Microsoft und Moonshot. Die Abrechnung erfolgt über GitHub AI Credits, mit Stufen von einem kostenlosen Plan bis hin zu individuellen Plänen und Organisationsplänen.
