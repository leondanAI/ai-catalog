Microsoft und OpenAI ordnen Partnerschaft neu — Exklusivität endet, OpenAI öffnet sich für AWS und Google Cloud

Industrie Apr 27, 2026·CNBC

Microsoft und OpenAI haben den Vertrag neu geschrieben, der ihre Beziehung seit 2019 geprägt hat — eine Neuordnung, die die exklusiven Bindungen zwischen den beiden Unternehmen deutlich lockert.

Was sich geändert hat

Gemäß der geänderten Vereinbarung: Microsoft beendet seine Zahlungen aus der Umsatzbeteiligung an Azure-Einnahmen an OpenAI. OpenAI zahlt weiterhin bis 2030 eine Umsatzbeteiligung an Microsoft, vorbehaltlich einer später gemeldeten Gesamtobergrenze von rund 38 Mrd. USD. OpenAI kann seine Produkte nun über jede Cloud verkaufen — einschließlich Amazon Web Services und Google Cloud — womit die seit 2019 bestehende Exklusivität endet, auch wenn Azure für OpenAI die primäre Cloud bleibt und neue Produkte zuerst erhält. Die „AGI-Klausel“, die es Microsoft erlaubt hätte, sich von Verpflichtungen zurückzuziehen, falls AGI als erreicht erklärt würde, entfällt; die Bedingungen der Umsatzbeteiligung sind nun unabhängig vom technologischen Fortschritt von OpenAI.

Hintergrund

Der annualisierte Umsatz von Anthropic wuchs von rund 9 Mrd. USD Ende 2025 auf mehr als 30 Mrd. USD bis Anfang April 2026 und übertraf damit erstmals die Run-Rate von OpenAI. OpenAI bereitet zudem einen geplanten Börsengang vor und baut sein Werbegeschäft aus — beides erforderte mehr operative Flexibilität, als der alte Vertrag zuließ.

Warum es wichtig ist

Unternehmenskunden können OpenAI-Modelle nun auf ihrer bestehenden AWS- oder Google-Cloud-Infrastruktur betreiben, ohne den Umweg über Azure nehmen zu müssen — ein bedeutender Wandel für Beschaffungs- und Compliance-Teams.
