Mistral veröffentlicht offene Gewichte für Mistral Large 4, ein Modell mit 1 Billion Parametern, API zu 0,70/2,10 US-Dollar

Modelle Oct 29, 2026·Mistral AI

Mistral AI veröffentlichte die Gewichte von Mistral Large 4 am 29. Oktober auf Hugging Face, nach einer öffentlichen Vorschau Anfang des Monats. Das Repository heißt mistralai/Mistral-Large-4-1T-A52B. Es ist das Flaggschiff-Modell des französischen Unternehmens hinter Le Chat und eines der größten Modelle, die man überhaupt herunterladen kann.

Das Modell in Zahlen

Größe: etwa 1 Billion Parameter in einem Mixture-of-Experts-Design, davon etwa 52 Milliarden aktiv (49 Milliarden pro Token, laut Model Card).
Kontext: 1 Million Token.
Input: Text und Bilder; die Ausgabe ist Text. Laut Mistral unterstützt das Modell mehr als 160 Sprachen.
Reasoning: ein Modell sowohl für Anweisungen als auch für Reasoning, mit den Aufwandsstufen Low, Medium und High.
Hardware: Die Einsatzbeispiele in der Model Card verwenden 8 GPUs, zudem ist eine quantisierte NVFP4-Version für NVIDIA-Blackwell-GPUs verfügbar.

Lizenz und Preis

Die Gewichte stehen unter der Mistral Ecosystem Open-Weight License, einer modifizierten MIT-Lizenz. Man kann das Modell nutzen, verändern, feinabstimmen und darauf aufbauende Produkte verkaufen. Die einzige Bedingung: Unternehmen, die das Modell selbst als gehosteten Dienst anbieten, benötigen eine separate kommerzielle Lizenz von Mistral.

Wer es nicht selbst hosten möchte, zahlt über Mistrals API 0,70 US-Dollar pro Million Input-Token, 0,07 US-Dollar für zwischengespeicherten Input und 2,10 US-Dollar pro Million Output-Token. Das Modell ist außerdem über OpenRouter, Microsoft Foundry und NVIDIAs gehostete Endpunkte verfügbar und läuft auf vLLM und SGLang.

Leistung laut Mistral

Mistral gibt 48 % im Artificial Analysis Coding Agent Index an, womit das Modell in etwa gleichauf mit GLM-5.3 liegt, dabei aber 47 % weniger Token pro Aufgabe benötigt, sowie 41 % bei Terminal-Bench 4.0, 13 Punkte über der Vorschauversion. Dies sind Angaben des Unternehmens.

Für wen das relevant ist

Large 4 richtet sich an Unternehmen, die ein Modell der Spitzenklasse auf eigenen Servern benötigen: für Daten, die das Haus nicht verlassen dürfen, für europäisches Hosting oder für das Feintuning mit eigenem Material. Für Einzelpersonen ist der API-Preis die relevantere Zahl.

Was das für die Wahl eines offenen Modells bedeutet

Wer bereits offene Gewichte nutzt, etwa DeepSeek, erhält mit Large 4 eine neue Option zum Testen, insbesondere für mehrsprachige Aufgaben und Aufgaben mit Bild-Input. Zunächst sollte man die Hardware-Anforderungen prüfen: Ein Modell mit 1 Billion Parametern ist ein Fall für ein Rechenzentrum, nicht für einen Laptop.

Wer plant, Zugang zum Modell weiterzuverkaufen, sollte die Lizenz genau lesen: Anbieter gehosteter Dienste benötigen eine separate Vereinbarung mit Mistral.
