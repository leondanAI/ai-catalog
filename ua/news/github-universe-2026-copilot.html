GitHub Universe 2026: застосунок Copilot від issue до merge, маршрутизація моделей Copilot Fusion і Copilot для всіх клієнтів Enterprise

Інструменти Oct 28, 2026·GitHub

GitHub використав свою конференцію Universe 28 жовтня, щоб перепозиціонувати GitHub Copilot з помічника з програмування на систему для завершення роботи. Для тих, хто обирає інструмент для кодування, найважливіші чотири анонси.

Застосунок Copilot

Новий десктопний застосунок, наразі доступний для завантаження на Mac з чипами Apple silicon, створений для виконання завдання від issue до merge. Він поєднує агентів та інструменти в різних проєктах, а також охоплює роботу навколо коду, як-от написання специфікацій і аналіз телеметрії. Усередині нього проєкти Copilot, доступні з дня запуску, виконують роботу агентів паралельно в кількох репозиторіях з єдиним місцем для відстеження прогресу. За сесією хмарного агента можна стежити й керувати нею із застосунку, VS Code, CLI або вебінтерфейсу.

Copilot Fusion

Fusion — це маршрутизатор моделей: ви обираєте його в меню моделей, і для кожного запиту він вирішує, які моделі використати і як саме — від однієї моделі до кількох, що складають чернетку, критикують і допрацьовують результат. Він загальнодоступний у VS Code, Copilot CLI, застосунку Copilot та IDE JetBrains. Fusion Standard доступний у всіх планах, включно з безкоштовним; Fusion High потребує Pro+, Max, Business або Enterprise; Fusion Max потребує Max, Business або Enterprise. Окремої плати немає: ви сплачуєте ШІ-кредити за кожну викликану модель.

GitHub стверджує, що Fusion Max набрав результат у межах двох пунктів від Claude Opus 5.5 Max за індексом Artificial Analysis Coding Agent Index, при цьому вдвічі дешевше і на 40% швидше на одне завдання. Це твердження самого GitHub.

Code review Max

Функція перевірки коду Copilot отримує третій, найретельніший рівень — Max, у публічному попередньому перегляді. Він використовує кілька моделей з високим рівнем міркувань, і за документацією GitHub, середня вартість становить близько $10 у ШІ-кредитах за перевірку, проти близько $1.50 для стандартного рівня Balanced і $0.25 для Lite.

Copilot включено для GitHub Enterprise

Клієнти GitHub Enterprise тепер можуть користуватися всіма функціями Copilot, включно із застосунком, перевіркою коду та автоматизаціями, без придбання окремої підписки Copilot. Вони платять за використані ШІ-кредити. Наразі це оформлюється через відділ продажів GitHub, а самообслуговування обіцяють пізніше; наявні клієнти Copilot Business та Enterprise можуть зберегти свої поточні плани. Для фізичних осіб Copilot коштує $10 на місяць за план Pro, $39 за Pro+ і $100 за Max.

Що це означає для тих, хто обирає агента для кодування

Якщо ваша компанія вже платить за GitHub Enterprise, запитайте у свого адміністратора про варіант на основі кредитів, перш ніж купувати окремого агента для кодування: можливо, ви отримаєте Copilot без нового контракту з оплатою за місце.

Якщо ви порівнюєте Copilot з Claude Code, Fusion і code review Max роблять ці продукти ближчими один до одного, а вартість тепер залежить від використаних кредитів, а не кількості місць. Див. Claude Code проти GitHub Copilot.
