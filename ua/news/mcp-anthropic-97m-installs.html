Model Context Protocol подолав позначку у 97 мільйонів завантажень SDK на місяць, тепер під наглядом Agentic AI Foundation від Linux Foundation

Інфраструктура Apr 30, 2026·Anthropic Blog

Model Context Protocol (MCP) перевищив 97 мільйонів завантажень SDK на місяць для Python і TypeScript, повідомила Anthropic 9 грудня 2025 року.

Що таке MCP

MCP — це відкритий стандарт, що визначає, як моделі ШІ підключаються до зовнішніх інструментів, баз даних та API. Написаний один раз, він працює з будь-якою сумісною з MCP моделлю ШІ.

Нова модель управління

Станом на 9 грудня 2025 року MCP перестав бути виключно проєктом Anthropic. Тепер ним керує Agentic AI Foundation від Linux Foundation, засновниками якої стали Anthropic, Block та OpenAI.

Повсюдне впровадження

Усі провідні постачальники ШІ тепер постачають інструментарій, сумісний з MCP: OpenAI, Google, xAI, Mistral та інші. Claude Code, Cursor, Windsurf та інші інструменти для розробки на основі ШІ використовують MCP як основний механізм підключення інструментів.

Чому 97 мільйонів важливі

З показником у 97 мільйонів завантажень SDK на місяць MCP досяг рівня впровадження, властивого інфраструктурним рішенням — подібно до того, як REST API стали стандартом за замовчуванням для веб-сервісів. Це фактичний стандарт для комунікації між ШІ та інструментами.
