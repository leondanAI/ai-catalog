Claude Opus 4.8 — стрибок на 27 пунктів з математики, Dynamic Workflows, дешевший Fast режим

Моделі May 28, 2026·Anthropic Blog

Anthropic запустила Claude Opus 4.8 28 травня 2026 року — всього через 41 день після Opus 4.7. Цей випуск позиціонується як значне оновлення якості: швидші відповіді, краща узгодженість у довгих контекстах та драматичний стрибок у математичному мисленні.

Математичний бенчмарк: 69.3% до 96.7%

Найвразливіше поліпшення стосується USAMO 2026 — бенчмарку США Mathematical Olympiad. Opus 4.8 набирає 96.7%, порівняно з 69.3% на Opus 4.7. Це стрибок на 27 пунктів за 41 день, що робить Opus 4.8 найсильнішою загальнодоступною моделлю з просунутої математики.

Opus 4.8 також приблизно у чотири рази менш схильна пропускати вади у своєму коді без їх позначення та активно сигналізує про невпевненість, замість того щоб впевнено галюцинувати.

Dynamic Workflows в Claude Code

Найбільшою agentive функцією є Dynamic Workflows: Claude Code тепер може планувати велике завдання, запускати до 1000 паралельних субагентів, розподіляти роботу між ними та перевіряти результати за вашим набором тестів — все без втручання людини. Функція розроблена для міграцій у масштабі репозиторію та рефакторингу кодів з сотнями тисяч рядків, які раніше вимагали команди інженерів.

Ціноутворення: той же базис, дешевший Fast режим

Стандартне ціноутворення залишається на рівні $5 за мільйон токенів вхідних даних і $25 за мільйон токенів вихідних даних — однаково як на Opus 4.7. Велика зміна відбулася в Fast режимі: він зменшується з $30/$150 за мільйон токенів (Opus 4.7) до $10/$50 — 3-кратне скорочення вартості для робочих навантажень, чутливих до затримок. Кешування запитів дає економію до 90%; пакетна обробка пропонує 50% знижку.

Opus 4.8 доступна в Claude.ai для передплатників Pro, Max, Team та Enterprise, а також через Anthropic API, AWS Bedrock, Google Cloud Vertex AI та Microsoft Foundry.

Mythos Preview незабаром

Окремо Anthropic підтвердила, що Claude Mythos Preview — модель кібербезпеки з обмеженим доступом — буде доступна для схвалених організацій "у найближчі тижні." Під час її 30-денного перегляду Mythos та приблизно 50 партнерських організацій виявили більше 10000 вразливостей високої або критичної серйозності в системно важливому ПЗ.
