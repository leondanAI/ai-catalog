Notion Developer Platform 3.5: середовище виконання Workers, одностороння синхронізація баз даних, двосторонні вебхуки та нові API для агентів

Інструменти May 13, 2026·Notion Blog

Notion випустив Developer Platform 3.5 13 травня 2026 року — наймасштабніше оновлення для розробників в історії компанії. Реліз представляє кілька нових можливостей, які перетворюють Notion із робочого простору для знань на програмовану платформу з агентним виконанням на основі ШІ.

Середовище виконання Workers

Середовище виконання Workers — це хмарне середовище Notion для власного коду, яке розгортається через новий Notion CLI і виконується в ізольованому середовищі всередині Notion. Логіка — автоматизації, перетворення даних, інтеграції — тепер існує поряд із контентом, а не в зовнішніх сервісах. База даних Notion тепер може викликати функцію, обробити дані, звернутися до зовнішнього API та записати результати назад — усе це в межах середовища Notion, без використання Zapier, Make чи власної бекенд-інфраструктури. Workers безкоштовні на час бета-тестування, з ціноутворенням на основі кредитів Notion, яке почне діяти з 11 серпня 2026 року.

Database Sync

Database Sync, наразі в стадії бета-тестування, дозволяє Workers отримувати дані із зовнішніх API у бази даних Notion — наприклад, імпортувати тікети Zendesk або записи Salesforce безпосередньо в Notion. З'єднання є одностороннім: зовнішні дані надходять у Notion, надаючи командам актуальне, постійно оновлюване представлення інформації, яке раніше вимагало ручного імпорту або разової автоматизації.

Двосторонні вебхуки та нові API для агентів

Двосторонні вебхуки розширюють модель подій в обох напрямках: Notion може отримувати вхідні вебхуки від зовнішніх сервісів для запуску робочих процесів і надсилати вихідні вебхуки при зміні вмісту в Notion. Реліз також представляє нові можливості для агентів: External Agents API (альфа) для підключення зовнішніх агентів до Notion, інструменти для кастомних агентів, побудовані як Workers (бета), та Notion Agent SDK (альфа) для створення агентів, що працюють зі структурованими даними Notion.

Чому це важливо

Developer Platform 3.5 позиціонує Notion як платформу, де власний код і агенти працюють зі структурованими, взаємопов'язаними даними, а не лише з документами. Для команд, які вже використовують Notion як свій операційний центр, Workers і Database Sync відкривають можливості автоматизації та інтеграції, які раніше вимагали окремої інженерної роботи. Для розробників ШІ нові API для агентів і SDK перетворюють бази даних Notion на основу для створення автономних агентних робочих процесів.
