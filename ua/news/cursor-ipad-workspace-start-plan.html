Cursor додає агентів для Google Workspace, застосунок для iPad і бюджетний план для Індії

Інструменти Aug 3, 2026·Cursor

Cursor випустив три окремі оновлення в період з 28 липня по 3 серпня, і разом вони говорять про напрямок розвитку більше, ніж будь-яке з них окремо.

Плагіни для Google Workspace

Нові інтеграції дозволяють агентам Cursor читати, писати та діяти в Google Workspace — Gmail, Google Drive і Google Calendar. Це виводить агента за межі репозиторію. Інструмент для написання коду, який може прочитати специфікацію з Drive, перевірити календар і надіслати лист, — це вже не просто інструмент для написання коду.

Cursor для iPad

Підтримка iPad з'явилася на всіх платних планах, із закріпленими бічними чатами, що дозволяють спостерігати за роботою кількох агентів одночасно, повноцінним переглядом PR та реорганізованими інструментами для вхідних. Дизайн показує, чим став цей робочий процес: цінність полягає в нагляді за паралельними агентами, а не в наборі коду на планшеті.

Cursor Start

Для індійських розробників запущено бюджетний план за Rs 649 на місяць, що включає доступ до моделей Grok 4.5 і Composer, а також віддалене керування через iOS. Регіональне ціноутворення на такому рівні — це продуманий ринковий крок, а не просто знижка.

Чому це важливо

Спільна нитка тут — нагляд. Router (22 липня) обирає модель для кожного запиту, iPad дозволяє спостерігати за кількома агентами одночасно, а Workspace дає цим агентам доступ за межі коду. Cursor створює продукт для розробника, який запускає роботу і перевіряє її, а не пише кожен рядок сам.

Доступ до Workspace варто ретельно оцінити, перш ніж його вмикати. Агент із правом запису в пошту та календар має інший профіль ризику, ніж той, що обмежений git-репозиторієм, і масштаб наслідків помилки відповідно зростає.

Що перевірити перед увімкненням доступу до Workspace

Доступ на читання й запис до пошти, файлів і календаря суттєво розширює те, до чого може дотягнутися агент для написання коду. Надавайте найвужчі права доступу, необхідні для роботи процесу, тримайте агента подалі від спільних дисків, до яких у нього немає причин звертатися, і переконайтеся, що є аудиторський слід, перш ніж дозволяти йому діяти без нагляду. Ризик полягає не стільки в неправильній поведінці самого інструмента, скільки в тому, що агент виконає інструкції, знайдені в якомусь документі.

Варто також стежити за регіональним ціноутворенням: Rs 649 на місяць — це серйозна заявка на ринок розробників, який значною мірою був відрізаний від передових інструментів через ціну, а там, куди рухається Cursor у цьому напрямку, конкуренти зазвичай ідуть слідом.
