Claude Code Review став загальнодоступним для Team і Enterprise з трьома рівнями перевірки — Quick, Standard і Deep

Інструменти Oct 15, 2026·Anthropic

Anthropic вивела Code Review з режиму дослідницького попереднього перегляду 15 жовтня. Тепер цей інструмент загальнодоступний для організацій на планах Claude Team і Enterprise. Code Review є частиною Claude Code: щойно адміністратор вмикає функцію, Claude переглядає pull request-и у ваших репозиторіях GitHub і залишає коментарі до рядків, які викликають зауваження.

Як це працює

Кілька агентів паралельно аналізують зміни та навколишній код, шукаючи логічні помилки, вразливості безпеки та неопрацьовані межові випадки. Етап верифікації перевіряє кожну знахідку щодо коду, щоб відфільтрувати хибні спрацювання, а решту ранжує за ступенем критичності. Перевірка публікує вбудовані коментарі, підсумок і результат перевірки (check run). Вона ніколи не схвалює і не блокує pull request, тож рішення про злиття залишається за командою. За замовчуванням система шукає помилки, які могли б зламати продакшн, а не проблеми з форматуванням чи відсутні тести, і команди можуть налаштовувати її за допомогою файлу REVIEW.md.

Що змінилося при переході до загальної доступності

Швидкість: за даними Anthropic, більшість перевірок тепер завершуються за 6–10 хвилин, що приблизно втричі швидше, ніж приблизно 20 хвилин під час попереднього перегляду.
Рівні перевірки: Quick (найшвидший і найдешевший), Standard (за замовчуванням) або Deep (найретельніший, найповільніший і найдорожчий), налаштовується для організації і, за потреби, для кожного репозиторію окремо.
Коли запускається: кожен репозиторій може проходити перевірку одноразово при відкритті pull request, після кожного push або лише тоді, коли хтось пише коментар "@claude review".

Ціна та доступність

Фіксованої ціни за перевірку немає. Перевірки тарифікуються за обсягом використаних токенів через кредити використання, окремо від включеного в план обсягу використання, а вартість залежить від рівня перевірки, розміру змін та частоти запуску перевірок. Адміністратори можуть встановити ліміт місячних витрат. Відповідні організації рівня Enterprise можуть отримати щонайменше $10,000 у кредитах Code Review до 15 січня 2027 року; кредити втрачають чинність через 30 днів після отримання. Code Review працює з GitHub, включно з GitHub Enterprise Server, і недоступний для організацій із конфігурацією Zero Data Retention або HIPAA.

Варіант від GitHub того самого дня

Також 15 жовтня GitHub зробив загальнодоступним AI Scan для pull request-ів. Він вужчий за призначенням: шукає вразливості безпеки у змінах pull request-ів мовами та у фреймворках, які не охоплює CodeQL, зокрема PHP, Shell, Terraform і Dockerfile. Для публічних репозиторіїв це безкоштовно; для приватних потрібен GitHub Code Security або Advanced Security, ліцензія Copilot не потрібна. Його знахідки мають рекомендаційний характер і не можуть блокувати злиття.

Що це означає, якщо ви обираєте інструмент для перевірки коду

Якщо вам потрібен другий рецензент для пошуку помилок і логічних прорахунків, Claude Code Review охоплює ширше коло завдань. Спробуйте його на кількох репозиторіях, налаштувавши перевірки на одноразовий запуск або запуск за запитом, а вже потім вирішуйте щодо варіанту "після кожного push", який суттєво збільшує вартість.

Якщо ваш головний пріоритет — безпека, і ви вже оплачуєте продукти безпеки GitHub, AI Scan іде в комплекті з тим, що у вас уже є. Команди, які вже користуються GitHub Copilot, можуть зважити обидва варіанти: Claude Code vs GitHub Copilot.
