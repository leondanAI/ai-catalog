Від 20 до 200+ прийнятих PR на місяць: як один інженер працює з Claude Code

Інструменти Nov 3, 2026·The Pragmatic Engineer

Розсилка The Pragmatic Engineer провела конкурс есе серед читачів, і робота-переможець, опублікована 3 листопада, — розповідь з перших рук про те, як виглядає програмування з ШІ на повній швидкості. Її автор, Neil Kakkar, має дев’ять років досвіду, зокрема в Bloomberg і PostHog, а зараз він перший інженер у Tano, стартапі приблизно з десяти людей.

Цифри

На попередніх роботах Kakkar приймав від 8 до 20 пул-реквестів на місяць. У Tano — понад 200, приблизно в 11 разів більше, ніж у PostHog. За його словами, відкатів приблизно в шість разів менше, переважно тому, що помилки виправляють наступною зміною, а медіанний час від відкриття PR до злиття — менше години. Уся команда зливає близько 30 PR на день.

Як усе влаштовано

Усе тримається на Claude Code. У кожного інженера одна підписка Claude Max 20x; Kakkar оцінює, що за цінами API його використання коштувало б понад $8 000 на місяць. Він працює в десктопному застосунку Claude Code із вбудованим браузером, а не в командному рядку, веде 3–5 задач паралельно й дає агентам від однієї до двох годин на кожну фічу, включно з їхніми власними перевірками та скриншотами. Кожен PR автоматично перевіряє агент Claude Code у GitHub Actions, а для ризикованих змін є глибший агент-рев’юер. На більшості PR цей агент — єдиний рев’юер. Контекст щодо кожної частини продукту записаний у файлах AGENTS.md, щоб агенти могли його знайти.

Що пішло не так

Збої він перелічує прямо. Агент помножив грошові суми на 100, що неправильно для валют на кшталт бахрейнського динара; це помітили після деплою й виправили за годину. Блокувальна міграція бази даних на великій таблиці зупинила приймання даних. Інша міграція без запобіжників двічі заплатила частині авторів. Такі правила тепер записані в інструкціях агента-рев’юера.

Людська ціна теж у списку: постійне перемикання контексту, дедалі менше людей, які знають конкретний шматок коду, шаблонний дизайн і впирання в ліміти тарифу, коли агенти крутяться в циклах. Власне правило Kakkar — закінчувати о 18:00 і залишати робочі пристрої в офісі.

Застереження редактора

Gergely Orosz, автор розсилки, додає, що загалом у галузі кількість PR із січня зросла приблизно вдвічі, тож цей випадок значно вищий за середній, а сама лише швидкість не доводить, що продукт успішний. Зрілим компаніям, вважає він, варто змінювати процеси обережніше.

Що це означає, якщо ви обираєте агента для коду

Виграш дав процес, а не лише інструмент. Записаний контекст, автоматичний рев’юер на кожному PR і правила, винесені з інцидентів, дали не менше, ніж модель.

Закладайте ліміти. Навіть найвищий тариф Claude вичерпувався, коли агенти працювали в циклах, тож перевірте ліміти, перш ніж планувати нічні прогони. Якщо порівнюєте варіанти, дивіться Codex чи Claude Code і наш список ШІ-інструментів для програмування.
