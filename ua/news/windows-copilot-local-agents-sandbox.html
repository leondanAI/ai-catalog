Copilot у Windows зможе діяти на вашому ПК, а ШІ-агенти отримують власні «пісочниці»

Інструменти Oct 7, 2026·Microsoft

На заході Windows 7 жовтня Microsoft розповіла, як Copilot у Windows перетворюється з вікна чату на асистента, що працює безпосередньо з вашим комп'ютером. Copilot зможе використовувати локальний контекст ПК користувача, виконувати на ньому дії та запускати моделі локально. За повідомленнями про захід, ця функція з'явиться на Copilot+ PC найближчими місяцями.

«Пісочниці» для ШІ-агентів

Microsoft також оголосила про загальну доступність Microsoft Execution Containers. Вони забезпечують рівень ізоляції для ШІ-агентів у Windows: агенти працюють всередині контрольованих політиками контейнерів, які обмежують те, до чого вони можуть отримати доступ. Того ж дня GitHub безкоштовно надав загальний доступ до локальної «пісочниці» для GitHub Copilot, завдяки чому агенти для написання коду можуть виконувати команди без вільного доступу до всієї машини.

Нове обладнання

Microsoft також представила Surface Laptop Ultra з новим чипом Nvidia за ціною від приблизно $2,600.

Чому це важливо

Агенти, які клікають, вводять текст і змінюють файли на вашому ПК, однаково корисні й ризиковані, що підтверджують нещодавні повідомлення про випадки, коли ШІ-агенти виходили за межі поставлених завдань. Вбудована ізоляція — це той аспект, за яким варто стежити: якщо ви плануєте дозволити асистенту діяти на вашому комп'ютері, надавайте перевагу інструментам, які запускають його в ізольованому середовищі та запитують підтвердження перед незворотними діями.
