Anthropic запускає функцію пам'яті для Claude Managed Agents

Tools Apr 18, 2026·Anthropic Blog

Anthropic запустила Memory — керований сервіс, який надає агентам Claude постійну пам'ять між сесіями. Досі кожна розмова агента починалася з нуля: усе, що агент дізнавався про кодову базу, клієнта чи робочий процес, зникало одразу після завершення сесії.

Що змінилося

Memory витягує ключову інформацію з розмов агентів і показує її знову, коли вона стає релевантною, замість того щоб відтворювати повні стенограми. Практичний ефект відчутний на контекстному вікні — агент зберігає те, що важливо, без необхідності тримати повну історію, тож контекст залишається компактним, а вартість кожного запуску — передбачуваною.

Memory побудована як шар на основі файлової системи: записи зберігаються у вигляді файлів, які можна експортувати, керувати ними через API та обмежувати доступ правами. Кожна зміна фіксується в журналі, з аудиторським слідом для кожної сесії та кожного агента, тож команди можуть відкочувати, редагувати або видаляти те, що зберіг агент.

Доступність

Сервіс запущено в публічній бета-версії на Claude Platform 23 квітня 2026 року для Claude Managed Agents. Серед ранніх користувачів, названих Anthropic, — Netflix, Rakuten, Wisedocs та Ando, які використовують його для скорочення повторюваної налаштувальної роботи та зменшення помилок у довготривалих робочих процесах.

Разом з анонсом Anthropic відкрила хакатон для розробників на $100K, побудований навколо Claude Opus 4.7, із призовим фондом $100K у вигляді кредитів на API, який триватиме з 21 по 28 квітня.

Чому це важливо

Постійна пам'ять — це те, що відрізняє чат-бота від агента, який стає кращим у своїй справі. Без неї кожне покращення доводиться вручну вносити в промпти; з нею агент самостійно накопичує знання, а оператору більше не потрібно повторно пояснювати той самий контекст. Для команд, які використовують агентів для обробки запитів підтримки, рев'ю коду чи опрацювання документів, це усуває найбільше джерело рутинного обслуговування промптів.

Аудиторський слід важливий не менше за саму пам'ять: усе, що агент пам'ятає про клієнтів чи внутрішні системи, має бути доступним для перевірки та видалення, перш ніж підприємство впровадить це у виробництво.
