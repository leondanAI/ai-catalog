Про сервіс Zed

Zed — це редактор коду, повністю побудований на Rust, розроблений для забезпечення низької затримки та нативної продуктивності замість оболонки Electron, яку використовують такі редактори, як VS Code та Cursor. Zed 1.0 вийшов 29 квітня 2026 року, відзначивши п'ять років розробки та понад мільйон рядків коду на Rust.

Головна функція, представлена разом з версією 1.0, — це Parallel Agents (анонсована окремо 22 квітня 2026 року): користувачі можуть запускати кілька ШІ-агентів одночасно, кожен з яких незалежно працює над різною частиною кодової бази, замість того, щоб чекати завершення одного завдання агента перед початком іншого. Zed також створив Agent Client Protocol (ACP) — стандарт, що дозволяє зовнішнім агентам, таким як Claude Agent, Codex, OpenCode та Cursor, працювати всередині редактора Zed. У серпні та вересні 2026 року Zed анонсував та відкрив публічну бета-версію Delta — нового продукту, позиціонованого як заміна pull request'ів: багатокористувацьке середовище на базі DeltaDB для написання коду з агентами та перевірки їхніх результатів, що працює локально та в браузері через WebAssembly, а також синхронізується зі сторонніми агентами, такими як Claude Code.

Всередині редактора Zed надає прямий доступ до моделей від Anthropic, OpenAI та Google, без необхідності окремого налаштування API-ключів для кожного провайдера.

План Personal у Zed назавжди безкоштовний, але обмежує використання ШІ, розміщеного Zed, 2000 прийнятими прогнозами редагування; необмежене використання вимагає власних API-ключів або зовнішнього агента. План Pro коштує 10 доларів США на місяць і включає необмежені прогнози редагування плюс 5 доларів США щомісячних токенів з оплатою за фактичне використання понад цю суму, а також надає 14-денний безкоштовний пробний період. План Business коштує 30 доларів США за місце на місяць і додає загальноорганізаційні політики моделей ШІ, засоби контролю управління даними, уніфіковану видимість витрат та рольовий контроль доступу; він не включає фіксованого обсягу кредитів LLM, а для 25+ місць доступні комерційні пропозиції (order forms).

Як продукт версії 1.0, екосистема розширень та плагінів Zed все ще менша, ніж у VS Code чи JetBrains, а нативна архітектура на Rust означає, що деякі розширення VS Code несумісні. Нова функція Parallel Agents також може призводити до конфліктів координації, коли кілька агентів торкаються коду, що перетинається.

Zed підходить розробникам, які хочуть швидкий, ресурсоефективний редактор із справжньою можливістю паралельних ШІ-агентів, а також командам, яким потрібне опубліковане, централізоване ціноутворення для управління ШІ без необхідності впроваджувати важкий корпоративний інструмент.

  • Agent Client Protocol (ACP) дозволяє зовнішнім агентам, таким як Claude Agent, Codex, OpenCode та Cursor, працювати всередині Zed
  • Прямий доступ до моделей від Anthropic, OpenAI та Google, вбудований у редактор
  • Рівні Business та Pro мають чітке, опубліковане ціноутворення за місце на місяць
Недоліки
  • Версія 1.0 — екосистема розширень та плагінів менша, ніж у VS Code чи JetBrains
  • Безкоштовний план Personal обмежує ШІ, розміщений Zed, 2000 прийнятими прогнозами редагування; для необмеженого використання потрібні власні API-ключі
  • Нативна архітектура на Rust означає, що деякі розширення VS Code несумісні
  • Функція паралельних агентів нова — координація кількох агентів може призводити до конфліктів

Часті запитання

Що таке Zed?
Zed — це високопродуктивний редактор коду, побудований на Rust творцями Atom та Tree-sitter. Він надзвичайно швидкий завдяки нативній архітектурі (без Electron), підтримує спільну роботу в реальному часі та включає вбудовану допомогу ШІ з використанням моделей від таких провайдерів, як Anthropic, OpenAI та Google.
Чи безкоштовний Zed?
Редактор Zed безкоштовний у використанні, а план Personal надає ШІ, розміщений Zed, безкоштовно до 2000 прийнятих прогнозів редагування, або необмежене використання, якщо ви використовуєте власні API-ключі. Понад це план Pro коштує 10 доларів США на місяць за необмежені прогнози редагування плюс 5 доларів США щомісячних ШІ-токенів, а для команд доступний план Business.
Чи швидший Zed за VS Code?
Так. Zed значно швидший за VS Code та Cursor (які побудовані на Electron), оскільки він написаний на Rust з рендерингом, прискореним через GPU. Час запуску, завантаження файлів та редагування відчуваються помітно швидшими, особливо на великих кодових базах.
Чи має Zed підтримку GitHub Copilot?
Zed має власну вбудовану інтеграцію ШІ з використанням моделей від таких провайдерів, як Anthropic, OpenAI та Google. Підтримка розширення GitHub Copilot обмежена — Zed не має такої багатої екосистеми розширень, як VS Code. Якщо ви покладаєтеся на конкретні розширення VS Code, Cursor буде безпечнішим вибором.
