Microsoft Ignite 2026: Word, Excel and PowerPoint Move Inside Copilot, While Copilot Code and Autopilot Stay in Early Access

Tools Nov 17, 2026·Microsoft Book of News

At Microsoft Ignite 2026 on November 17, Microsoft showed how its work assistant is turning from a chat window into a place where you write documents, delegate tasks and even build small apps. Some of it is live, much is still in the Frontier early-access program. Here is what users of Microsoft Copilot at work get.

Available now

Home. The new start screen of the Copilot app brings Chat and Cowork together, with one input box powered by Auto, which picks the model for each task. It is generally available and rolling out worldwide. When a request is complex, Auto can now suggest moving it from Chat to Cowork, and your context moves with it.

Word, Excel and PowerPoint inside Copilot. Office in Copilot is generally available: you can go straight from a conversation to a document, spreadsheet or deck, edit and co-author it as usual, and open the full app when needed. Files are saved to OneDrive and keep Microsoft 365 permissions and sensitivity labels. Microsoft says this is included in the Copilot subscription license, with no extra metering.

Copilot Managed Runtime, the hosting layer for apps built in Copilot Code, Copilot Cowork and Copilot Studio, is also generally available.

Frontier program only, for now

Copilot Code lets anyone describe a dashboard, tracker or app in plain words and have Copilot build it, using the same agentic technology as GitHub Copilot. It is in Frontier on Windows, web, iOS and Android, and Microsoft says it becomes generally available in December. The local sandbox works on Windows; macOS is "coming soon."

Autopilot is a long-running personal agent with its own identity, memory and tools. It can follow up on threads and run recurring work without a new prompt, and colleagues can @mention it in Teams. IT can block it at any time. It started rolling out to Frontier customers on November 17.

Copilot Workspaces, the successor to Copilot Notebooks, is a shared team space where Copilot tracks what changed. It is available in Frontier; adding your Autopilot to a workspace is "coming soon."

Today, a daily briefing across mail, calendar and Teams, is in private preview. The morning Today Brief is included with a Microsoft 365 Copilot license, while the all-day Today Feed requires Copilot credits.

Copilot on Windows: in preview

Copilot on Windows will be able to find, organize, move, copy or rename files on your PC from a plain-language request, help diagnose PC problems, and open from the new Windows Search on the taskbar if you opt in. All three are in preview, continuing the plan from its October Windows event.

What this means if you use Copilot at work

If your company already pays for Microsoft 365 Copilot, the Office-in-Copilot workflow is worth trying now: it costs nothing extra and keeps files inside your usual permissions. Copilot Code and Autopilot are not broadly available yet, so do not plan around them before December. For a general chat assistant outside Microsoft 365, see our Microsoft Copilot vs ChatGPT guide.
