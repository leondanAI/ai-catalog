Notion AI Moves to Credits: 1,500 Standard and 500 Select per Seat, Auto Model Router and Agents That Run 24+ Hours

Tools Oct 19, 2026·Notion

Notion rebuilt its AI agents and changed how AI usage is paid for. The update, announced on October 19 by co-founder Akshay Kothari, covers Notion AI's Notion Agent and Custom Agents, which now run on the sixth generation of Notion's agent harness.

The new credit system

All AI usage moves under one credit system, split in two:
Standard credits: 1,500 per Business or Enterprise seat each month, for work where Notion picks the model, mainly Auto.
Select credits: 500 per seat each month, for when you pick the model yourself or run your own Custom Agents.
Admins can buy extra credits for the workspace, for example for shared Custom Agents or high-credit models such as Fable and Astra. Team Custom Agents use Select credits unless an admin funds them from workspace credits. Notion says most users are unlikely to run out.

Timing: new customers are on the system from October 19; existing customers move on November 2, 2026, and admins get an email with details. Notion did not publish prices for extra credits.

Auto, longer tasks and faster agents

Auto routes each task to a model, sending simple requests to fast models and harder work to stronger ones, and switches if a model stalls. Notion says that across 20+ common tasks Auto gave results similar to Opus 5.5 and Astra at about 90% lower average cost, so credits go roughly ten times further.

A single agent task can now run for more than 24 hours, up from five minutes. Notion also reports Custom Agent runs about 30% cheaper in testing, agents up to 50% faster on web and mobile, and connections to hundreds of tools through MCP and connectors. A new "Review for me" mode has a separate model check actions for safety before the agent takes them.

Bring your own AI

ChatGPT: you can connect a ChatGPT Plus, Pro or Go account to your personal Notion Agent (not Custom Agents yet).
BYOK: your own API keys, in alpha for Enterprise customers through their account team.
Coming soon: an AI Command Center where admins see credit use by member, feature and agent, set spending limits and choose which models members can use.

What this means if you use Notion AI

If you are an admin on Business or Enterprise, check before November 2 which Custom Agents run often: they draw on Select credits, and the Command Center with spending limits is not out yet.

If you already pay for ChatGPT, connecting it to your personal Notion Agent is worth testing. If you mainly need agents that move data between many apps, compare options in Notion AI vs Zapier AI.
