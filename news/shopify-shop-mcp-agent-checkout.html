Shopify Launches Shop MCP: Any AI Agent Can Search Over 1 Billion Products and Check Out With Shop Pay

Tools Oct 13, 2026·Shopify

Shopify announced Shop MCP on October 13. It is one MCP connection that gives an AI agent or app three abilities at once: search Shopify Catalog, which holds more than 1 billion products, build carts, and complete checkout with Shop Pay. MCP (Model Context Protocol) is the open standard that AI assistants use to connect to outside tools.

How it works

The server is a remote endpoint at mcp.shop.com, and Shopify says any MCP client can connect, as can your own code. A skill description that agents can read on their own is published at mcp.shop.com/skill.md. The server exposes 17 tools, including product search and lookup, cart and checkout tools, checkout status, and order search with tracking for signed-in shoppers.

Search needs no API key. Carts and checkout also work without signing in. To pay with Shop Pay, the shopper signs in with Shop, which lets checkout use their saved addresses and Shop Pay. According to Shopify, MCP clients such as Claude and ChatGPT handle that sign-in, and custom code can use a device flow.

Who presses "buy"

By default, the shopper pays on the merchant's own checkout page through a link the agent hands over. A signed-in shopper can instead let the agent finish the purchase, but only after they have confirmed the total and a payment method. Each checkout belongs to one merchant, so items from three stores mean three checkouts.

For merchants, orders placed through an agent appear in the Shopify admin like any other order. At launch there are no webhooks, so developers have to poll for checkout status. Existing Catalog API integrations keep working with no changes. Shopify also released a command-line tool, @shopify/shop, for searching from the terminal.

What this means if you shop or build with AI agents

If you use an AI assistant for everyday tasks, shopping is becoming one of them. Claude and ChatGPT are the clients Shopify names as handling Shop sign-in. Before you let an agent complete a purchase, check the total, the store and the payment method it shows you, since that confirmation is the safeguard built into the flow.

If you are deciding which assistant to use, connector support is now a real factor alongside answer quality. See how the two compare in ChatGPT vs Claude.

If you build agents, Shop MCP is a low-effort way to add product search: no key and no merchant integration are needed to start, and checkout can be added later.
