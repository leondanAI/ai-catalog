Cursor Now Builds and Hosts Shareable Apps, and Lets You Talk to Its Agents by Voice

Tools Nov 6, 2026·Cursor Changelog

Cursor added two features to its AI code editor in the first week of November. One moves it closer to app builders such as Lovable and Replit; the other lets you talk to coding agents instead of typing.

Live Apps

Released on November 5, Live Apps lets you describe an app to a cloud agent and get it built, connected to a Postgres database if needed, set up with sign-in through Cursor SSO and deployed to hosting. You then share it with a link: with specific people, groups or your whole team, always behind Cursor sign-in. On individual plans, apps can also be shared publicly.

Before anything goes live, Cursor runs automated and agent-based checks for problems such as secrets left in app files or exposed credentials. If a check fails, the agent reports what to fix, and nothing is published until the checks pass and you confirm. Team admins can see every app, add their own review rules and unpublish apps. Live Apps is available on all paid plans with cloud agents enabled. Apps deploy from Cursor Origin or GitHub repositories; GitLab and other providers are listed as coming soon.

Voice chat with agents

On November 6, Cursor added two-way voice chat with agents in the Agents Window, the IDE, the web and Cursor for iOS, where "Hey Siri, call Cursor" starts a call with a new agent. You can keep talking while the agent works, ask what changed in a diff or check on a run, and the agent gives short spoken progress notes. Voice chat runs on Grok Voice; with Privacy Mode on, it runs with zero data retention. The older dictation feature stays as a separate option.

What this means if you are choosing a coding tool

Internal tools without a separate host. If you need a quick dashboard or form for your team, Cursor can now build, check and host it in one place, but sharing is tied to Cursor accounts unless you are on an individual plan.
