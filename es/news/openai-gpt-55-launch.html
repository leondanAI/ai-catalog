OpenAI lanza GPT-5.5, su modelo más avanzado con programación autónoma en Codex

Nuevo modelo Apr 23, 2026·OpenAI Blog

OpenAI ha lanzado GPT-5.5 — su modelo más capaz hasta ahora — marcando un giro decisivo de las respuestas de una sola interacción hacia flujos de trabajo autónomos de largo alcance.

Qué hay de nuevo

GPT-5.5 ya está disponible dentro de Codex, el producto existente de OpenAI para programación autónoma, lo que le permite escribir, probar y desplegar código de forma autónoma en proyectos de múltiples pasos. También aporta una investigación profunda más sólida, análisis de datos y la capacidad de operar software de escritorio y web de principio a fin sin guía humana.

Disponibilidad

El modelo se implementó para usuarios de ChatGPT Plus, Pro, Business y Enterprise el 23 de abril, y el acceso a través de la API de OpenAI llegó el 24 de abril.

Por qué importa

GPT-5.5 es el primer modelo insignia de OpenAI diseñado explícitamente para agentes que trabajan de forma autónoma durante horas, no segundos. Esto ejerce una presión considerable sobre Claude de Anthropic y Gemini de Google en el mercado empresarial de agentes autónomos.
