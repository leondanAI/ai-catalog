Cursor lanza su propio alojamiento de código — y agentes que arrancan sin repositorio

Herramientas Aug 17, 2026·Cursor

Cursor pasó agosto convirtiendo un editor en infraestructura. Tres lanzamientos que, en conjunto, describen una dirección clara.

Origin: Cursor aloja tu código

El 17 de agosto Cursor lanzó Origin, un alojamiento de repositorios de código integrado, en beta temprana. Se sincroniza con repositorios de GitHub de forma bidireccional en tiempo real, gestiona pull requests con sincronización con GitHub, y se integra con Vercel, Depot y Buildkite.

Que un editor de IA lance su propio alojamiento de código es un movimiento significativo. Significa que el agente ya no tiene que cruzar un límite de API para leer historial, abrir ramas o gestionar revisiones.

Agentes sin repositorio

El 27 de agosto los Cloud Agents dejaron de requerir GitHub o cualquier control de versiones de terceros para empezar a trabajar. Ahora un agente crea un repositorio de Origin en segundo plano, y el trabajo puede convertirse más tarde en un repositorio permanente con un nombre y una visibilidad elegidos. Se incluyen vista previa en navegador en vivo y publicación en Vercel.

Esto elimina por completo el paso de configuración: describes una tarea, obtienes código funcional con historial, y decides después si merece convertirse en un proyecto real.

Máquinas autoalojadas

El 2 de septiembre Cursor añadió máquinas autoalojadas, que mantienen la ejecución de herramientas dentro de tu propia red. Hay máquinas personales y grupos de equipo, uso del ordenador en Linux y Mac con control de escritorio, y soporte para AWS Lambda, Coder, Cloudflare, Daytona y Modal.

Ese es el desbloqueo para empresas. Muchas organizaciones no pueden permitir que un agente ejecute código en la infraestructura de un proveedor, y esto responde directamente a esa objeción.

Por qué importa

Vistos en conjunto, estos tres cambios llevan a Cursor de ser "funciones de IA en un editor" a convertirse en un lugar donde el código vive, se ejecuta y se despliega. Lo cual también significa que el costo de cambiar de herramienta va en aumento: un repositorio en Origin, agentes configurados en torno a él y ejecución en tus propias máquinas es un compromiso mucho más profundo que un editor que se puede sustituir.

Vale la pena sopesarlo antes de adoptar Origin como algo más que un espejo. La sincronización bidireccional con GitHub facilita hacerlo de forma segura: mantener a GitHub como fuente autorizada y dejar que Origin sea la copia de trabajo.
