Anthropic lanza Memory para agentes gestionados de Claude

Tools Apr 18, 2026·Anthropic Blog

Anthropic lanzó Memory, un servicio gestionado que dota a los agentes de Claude de una memoria persistente entre sesiones. Hasta ahora, cada conversación de un agente empezaba desde cero: todo lo que el agente aprendía sobre una base de código, un cliente o un flujo de trabajo desaparecía en cuanto terminaba la sesión.

Qué ha cambiado

Memory extrae la información clave de las conversaciones de los agentes y la vuelve a mostrar cuando resulta relevante, en lugar de reproducir transcripciones completas. El efecto práctico se nota en la ventana de contexto: el agente conserva lo importante sin arrastrar todo el historial, de modo que el contexto se mantiene compacto y el coste por ejecución resulta predecible.

Memory está construido como una capa basada en sistema de archivos: las entradas se almacenan como archivos que se pueden exportar, gestionar a través de la API y delimitar mediante permisos. Cada cambio queda registrado, con un rastro de auditoría por sesión y por agente, de modo que los equipos pueden revertir, redactar o eliminar lo que un agente ha retenido.

Disponibilidad

El servicio se lanzó en beta pública en Claude Platform el 23 de abril de 2026, para los Claude Managed Agents. Entre los primeros usuarios mencionados por Anthropic están Netflix, Rakuten, Wisedocs y Ando, que lo emplean para reducir el trabajo repetitivo de configuración y disminuir los errores en flujos de trabajo de larga duración.

Junto con el anuncio, Anthropic abrió un hackathon para desarrolladores con 100.000 dólares en premios, construido en torno a Claude Opus 4.7, que ofrece 100.000 dólares en créditos de API y se desarrolla del 21 al 28 de abril.

Por qué importa

La memoria persistente es lo que distingue a un chatbot de un agente que mejora en su trabajo con el tiempo. Sin ella, cada mejora hay que introducirla manualmente en los prompts; con ella, un agente acumula conocimiento por sí solo y el operador deja de tener que reexplicar el mismo contexto una y otra vez. Para los equipos que operan agentes en colas de soporte, revisión de código o procesamiento de documentos, esto elimina la mayor fuente de mantenimiento repetitivo de prompts.

El rastro de auditoría importa tanto como la propia memoria: todo lo que un agente recuerda sobre clientes o sistemas internos debe poder inspeccionarse y eliminarse antes de que una empresa lo lleve a producción.
