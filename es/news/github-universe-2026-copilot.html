GitHub Universe 2026: una app de Copilot de issue a merge, enrutamiento de modelos con Copilot Fusion y Copilot para todos los clientes empresariales

Herramientas Oct 28, 2026·GitHub

GitHub aprovechó su conferencia Universe del 28 de octubre para reposicionar GitHub Copilot, de asistente de código a sistema para terminar el trabajo. Cuatro anuncios son los más relevantes para quien esté eligiendo una herramienta de codificación.

La app de Copilot

Una nueva app de escritorio, por ahora disponible para descargar en Mac con chips Apple silicon, diseñada para llevar una tarea de issue a merge. Conecta agentes y herramientas entre proyectos y también cubre el trabajo en torno al código, como redactar especificaciones y analizar telemetría. Dentro de ella, Copilot projects, disponible desde el día del lanzamiento, ejecuta trabajo de agentes en varios repositorios en paralelo con un único lugar para seguir el progreso. Una sesión de agente en la nube puede seguirse y dirigirse desde la app, VS Code, la CLI o la web.

Copilot Fusion

Fusion es un enrutador de modelos: se selecciona en el menú de modelos y, para cada solicitud, elige qué modelos usar y cómo, desde un único modelo hasta varios que redactan, critican y revisan. Está disponible de forma general en VS Code, Copilot CLI, la app de Copilot y los IDE de JetBrains. Fusion Standard está en todos los planes, incluido Free; Fusion High requiere Pro+, Max, Business o Enterprise; Fusion Max requiere Max, Business o Enterprise. No hay un cargo aparte: se pagan créditos de IA por cada modelo que invoca.

GitHub afirma que Fusion Max obtuvo una puntuación a solo dos puntos de Claude Opus 5.5 Max en el Artificial Analysis Coding Agent Index, a la mitad del costo y en un 40% menos de tiempo por tarea. Esa es una afirmación propia de GitHub.

Code review Max

La revisión de código de Copilot recibe un tercer nivel, el más exhaustivo, Max, en vista previa pública. Utiliza varios modelos de razonamiento avanzado, y la documentación de GitHub sitúa el costo promedio en unos $10 en créditos de IA por revisión, frente a aproximadamente $1.50 para el nivel predeterminado Balanced y $0.25 para Lite.

Copilot incluido para GitHub Enterprise

Los clientes de GitHub Enterprise ya pueden usar todas las funciones de Copilot, incluidas la app, la revisión de código y las automatizaciones, sin comprar una suscripción aparte de Copilot. Pagan por los créditos de IA que consumen. Por ahora esto se gestiona a través de GitHub Sales, con autoservicio prometido más adelante, y los clientes actuales de Copilot Business y Enterprise pueden mantener sus planes vigentes. Para particulares, Copilot figura en $10 al mes para Pro, $39 para Pro+ y $100 para Max.

Qué significa esto si estás eligiendo un agente de codificación

Si tu empresa ya paga por GitHub Enterprise, consulta con tu administrador sobre la opción basada en créditos antes de comprar un agente de codificación aparte: podrías obtener Copilot sin un nuevo contrato por asiento.

Si estás comparando Copilot con Claude Code, Fusion y code review Max acercan a los dos productos, y el costo ahora depende de los créditos usados en lugar de los asientos. Consulta Claude Code vs GitHub Copilot.
