Cursor Freemium
IDE con IA, programación agéntica, múltiples repositorios, revisión de PR, agentes en paralelo

Cursor es un editor de código con IA desde el diseño, construido sobre VS Code, con programación agéntica, soporte para múltiples repositorios, agentes en paralelo y revisión automatizada de PR. Su línea de modelos propios ahora incluye Grok 4.7, Grok 4.6, Grok 4.5 y Composer 2.5, junto con modelos de terceros compatibles.

GitHub Copilot Freemium
Codificación con IA en VS Code, agentes en la nube, revisión de código, elección de modelos entre proveedores

GitHub Copilot es un asistente de codificación agéntico y multimodelo que va más allá del autocompletado, ofreciendo chat, un modo agente, agentes en la nube, revisión de código y una CLI, con modelos disponibles de proveedores como Anthropic, OpenAI, Google, xAI, Microsoft y Moonshot. Factura el uso mediante GitHub AI Credits, con niveles que van desde un plan gratuito hasta planes individuales y de organización.
