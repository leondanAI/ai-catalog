Acerca de V0 by Vercel

v0 de Vercel es un agente de IA para crear aplicaciones web. Describes lo que quieres en lenguaje natural (puedes adjuntar capturas o referencias de diseño) y genera código funcional que puedes previsualizar, editar y publicar. Lo desarrolla Vercel, la empresa detrás de Next.js y de su plataforma de hosting.

La versión actual es el "nuevo v0" posterior a febrero de 2026, un cambio que transformó el producto. Lo que antes era básicamente un generador de componentes de interfaz es hoy una plataforma agéntica de desarrollo full-stack: puedes importar repositorios de GitHub y trabajar con ramas y pull requests, usar un editor al estilo de VS Code, ejecutar aplicaciones full-stack en un entorno sandbox, conectar bases de datos y servicios (Snowflake, AWS), organizar el trabajo en Proyectos y Carpetas y hacer ajustes visuales con el Design Mode.

Por dentro, el asistente funciona con una familia de modelos llamados v0 Mini, Pro, Max y Max Fast, con un modelo de API publicado como vercel/v0-1.0-md. Desde el 31 de marzo de 2026 la facturación pasó de contar mensajes o créditos fijos a una medición por tokens, en la que los tokens de entrada y salida se convierten en créditos.

El plan gratuito cuesta 0 $/mes e incluye unos 5 $ de créditos mensuales (alrededor de 7 mensajes al día). Los planes de pago son Team a 30 $ por usuario/mes y Business a 100 $ por usuario/mes, además de un plan Enterprise con precio a medida. El antiguo plan Premium de 20 $/mes sigue existiendo para usuarios previos, pero está cerrado a nuevos registros. Los créditos comprados caducan un año después de la compra.

Su principal limitación es la previsibilidad del coste: la medición por tokens dificulta saber de antemano cuánto costará una sesión, y el trabajo full-stack intensivo consume créditos rápido. Los ~7 mensajes diarios del plan gratuito bastan para probarlo, pero no para construir en serio, y la plataforma está muy orientada al ecosistema de Vercel y Next.js.

v0 encaja bien con desarrolladores y equipos de producto que ya usan Vercel y quieren ir del prompt a una aplicación full-stack desplegada con rapidez, y con diseñadores o fundadores que buscan prototipar software real y funcional en lugar de maquetas estáticas.

Preguntas frecuentes

¿Qué es V0 by Vercel?
V0 es el generador de UI con IA de Vercel. Describe una interfaz en lenguaje natural y V0 genera código React y Tailwind CSS listo para producción que se despliega directamente en Vercel.
¿Cuánto cuesta V0?
Nivel gratuito con créditos limitados. Premium es $20/mes. Planes de equipo disponibles para proyectos colaborativos.
¿Puede V0 generar aplicaciones completas?
V0 se centra en la generación de UI frontend. Para apps completas, se integra con la plataforma de Vercel y puede generar rutas API y conexiones de base de datos.
¿Qué frameworks soporta V0?
V0 genera principalmente React con Tailwind CSS y componentes shadcn/ui. Compatible con Next.js y despliega de forma nativa en Vercel.
