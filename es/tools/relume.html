Acerca de Relume

Relume es una herramienta de IA para planificar y construir sitios web dirigida a agencias, freelancers y diseñadores. Describe el propósito y la audiencia de un sitio, y Relume genera un brief, un mapa de sitio completo y wireframes detallados para cada página, que se pueden personalizar antes de exportar o publicar. El producto ahora abarca dos ofertas: 'Build with Relume', un constructor de sitios web con IA, y 'Site Builder', una herramienta de creación de wireframes basada en una biblioteca de componentes.

La empresa se reposicionó recientemente: trasladó su dominio principal de relume.io a relume.ai, y lanzó una ruta de 'Publish' (actualmente en beta) que lleva un proyecto desde el brief hasta un sitio publicado y alojado en vivo, con Relume encargándose del dominio personalizado y el SSL. Esto se suma a la ruta original de 'Export', que ahora admite React (Tailwind CSS y shadcn/ui) además de Webflow y Figma. Relume también incluye un Library MCP para llevar componentes a otras herramientas de IA.

Entre las funciones clave se incluyen briefs, mapas de sitio y wireframes generados por IA, un generador de guías de estilo, colaboración ilimitada y una biblioteca de componentes con más de 1.000 secciones prediseñadas (hero, características, precios, FAQ, etc.) disponibles en Webflow, Figma y React. El plan gratuito de Build with Relume incluye alojamiento gratuito en un subdominio relume.live; el plan gratuito de Site Builder incluye 30 componentes de Webflow y 30 componentes de React.

Los precios se dividen entre los dos productos. Build with Relume tiene un plan gratuito para siempre (sin tarjeta requerida, uso compartido limitado de IA, sitios web ilimitados, alojamiento en relume.live) y un plan Pro desde $14/mes con un modelo de IA premium y acceso prioritario; el alojamiento en un dominio personalizado se cobra por separado, desde $12/proyecto/mes. Site Builder tiene un plan gratuito (30 componentes de Webflow + 30 de React) y niveles de pago: Starter desde $18/mes, Pro desde $40/mes (más de 1.000 componentes en todas las plataformas, hasta 300 componentes de almacenamiento), Team desde $36/mes por usuario con un mínimo de 3 usuarios, y un nivel Enterprise con precio personalizado. Todos los precios publicados usan una estructura de 'Desde $X/mes', por lo que el costo final depende de la configuración; actualmente no se publica ningún descuento por facturación anual.

Limitaciones: la ruta de Publish todavía está en beta, y usarla implica que el sitio en vivo se ejecuta en el alojamiento propio de Relume en lugar de una plataforma existente. La ruta de Export todavía requiere una cuenta separada de Webflow o Figma para ese flujo de trabajo. El precio final exacto de cualquier nivel depende del uso y la configuración, más que de una cifra fija única.

Relume es adecuado para agencias, freelancers y diseñadores que quieren acelerar la fase de planificación y creación de wireframes de un proyecto web, ya sea que pretendan entregarlo a Webflow, Figma o React, o publicarlo directamente a través del alojamiento propio en beta de Relume.

Preguntas frecuentes

¿Qué es Relume?
Relume es una herramienta de IA que genera briefs de sitios web, mapas de sitio y wireframes a partir de una descripción de texto, con una biblioteca de componentes para Webflow, Figma y React. También tiene una función de Publish en beta que puede alojar el sitio terminado directamente en un dominio personalizado, junto con el flujo de trabajo original de exportación a Webflow o Figma.
¿Cuál es la diferencia entre Relume y Framer?
El punto fuerte principal de Relume es la etapa de planificación impulsada por IA: briefs, mapas de sitio y wireframes, además de una amplia biblioteca de componentes para Webflow, Figma y React. Su ruta de Export entrega el trabajo a esas plataformas para la construcción final. Relume ahora también tiene una ruta de Publish en beta para alojar un sitio en vivo directamente, lo que reduce la brecha con herramientas como Framer, pero Publish es más nueva y menos consolidada que el flujo de exportación de Relume.
¿Relume es gratuito?
Sí, ambos productos de Relume tienen un plan gratuito. El plan gratuito de Build with Relume no requiere tarjeta e incluye uso compartido limitado de IA con alojamiento gratuito en un subdominio relume.live. El plan gratuito de Site Builder incluye 30 componentes de Webflow y 30 componentes de React. Los planes de pago comienzan desde $14/mes para Build with Relume Pro y desde $18/mes para Site Builder Starter.
¿Relume funciona con Figma?
Sí. La biblioteca de componentes y los wireframes generados por Relume se pueden exportar a Figma, así como a Webflow y React (Tailwind CSS y shadcn/ui), lo que permite a los equipos elegir la plataforma que se ajuste a su proceso de construcción.
