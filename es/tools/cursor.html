Acerca de Cursor

Cursor es un editor de código nativo de IA construido sobre VS Code, diseñado desde cero para desarrolladores que quieren la IA profundamente integrada en su flujo de trabajo de programación, en lugar de añadida como un complemento. A partir de 2026, ha superado los $1.000 millones en ingresos anualizados con más de 1 millón de desarrolladores de pago — una trayectoria de crecimiento notable para una herramienta de desarrollo.

Lo que distingue a Cursor es el contexto completo de la base de código. A diferencia de GitHub Copilot, que opera principalmente en el archivo actual, Cursor entiende todo tu repositorio. Puedes pedirle que refactorice una función en múltiples archivos, que explique por qué ocurre un error a tres capas de profundidad, o que implemente una nueva función de principio a fin — y actuará sobre toda tu base de código, no solo sobre lo que está abierto en ese momento.

Cursor es compatible con múltiples modelos de IA de vanguardia simultáneamente: Claude Opus 4.7, GPT-5.5 y Gemini, intercambiables según la tarea. Los Cloud Agents ejecutan tareas de programación en segundo plano mientras trabajas en otra cosa. Empresas como Stripe, OpenAI, Figma y Adobe utilizan Cursor como herramienta de desarrollo estándar.

Los precios cambiaron significativamente en junio de 2025, pasando de un modelo simple basado en solicitudes a un sistema basado en créditos vinculado al consumo real de tokens. Esto generó un rechazo significativo de la comunidad — los costes podían dispararse impredeciblemente. Cursor emitió una disculpa y reembolsos. A partir de 2026, los planes van desde gratuito (Hobby) hasta Pro a $20/mes, Pro+ a $60 y Ultra a $200. Los equipos pagan $40 por puesto.

La sobrecarga de migración desde VS Code es real — espera de 4 a 8 horas por desarrollador para transferir configuraciones y extensiones. Y Cursor cuesta el doble que GitHub Copilot en el nivel base. Pero para desarrolladores que trabajan con múltiples archivos complejos, las capacidades contextuales de toda la base de código justifican la diferencia.

Cursor 3 se lanzó en abril de 2026 con Composer 2 — un modelo de codificación propietario entrenado desde cero por Anysphere (no un fine-tune). Obtuvo 61.3 en CursorBench (+39% sobre el modelo anterior) y funciona a 200+ tokens/segundo con kernels GPU personalizados. Cursor ahora también soporta oficialmente JetBrains IDEs (IntelliJ, PyCharm, WebStorm) además de VS Code; la valoración alcanzó $60B en febrero 2026.

Ventajas
  • Mejor comprensión multíarchivo: lee y edita todo el código base con contexto
  • El modo Composer gestiona grandes refactorizaciones en decenas de archivos a la vez
  • Compatible con cualquier lenguaje, framework o estructura de proyecto
Desventajas
  • Facturación por créditos impredecible — los costes se disparan con uso intensivo
  • Trustpilot 1,7/5 — problemas de transparencia tras el cambio de precios en junio de 2025
  • Cuesta el doble que GitHub Copilot en el nivel base (20$ vs 10$)
  • Coste de migración: 4-8h por desarrollador desde VS Code
  • Pool de créditos de 20$ en Pro = ~225 solicitudes de Claude o ~500 de GPT-4o
