Claude Code Review disponible en version générale pour Team et Enterprise, avec des niveaux Quick, Standard et Deep

Outils Oct 15, 2026·Anthropic

Anthropic a fait sortir Code Review de l'aperçu de recherche le 15 octobre. L'outil est désormais disponible en version générale pour les organisations sur les offres Claude Team et Enterprise. Code Review fait partie de Claude Code : une fois qu'un administrateur l'active, Claude examine les pull requests dans vos dépôts GitHub et commente les lignes qu'il signale.

Fonctionnement

Plusieurs agents lisent en parallèle le changement et le code environnant, à la recherche d'erreurs logiques, de vulnérabilités de sécurité et de cas limites défaillants. Une étape de vérification confronte chaque constat au code afin d'écarter les faux positifs, et les constats restants sont classés par gravité. La revue publie des commentaires en ligne, un résumé et un check run. Elle n'approuve ni ne bloque jamais une pull request, de sorte que la décision de fusionner reste à l'équipe. Par défaut, elle recherche les bugs susceptibles de casser la production, et non les problèmes de formatage ou les tests manquants ; les équipes peuvent l'ajuster via un fichier REVIEW.md.

Ce qui change avec la disponibilité générale

Vitesse : selon Anthropic, la plupart des revues se terminent désormais en 6 à 10 minutes, soit environ trois fois plus vite que les quelque 20 minutes observées pendant l'aperçu.
Niveaux de revue : Quick (le plus rapide et le moins cher), Standard (le niveau par défaut) ou Deep (le plus approfondi, le plus lent et le plus coûteux), définis pour l'organisation et, si nécessaire, pour chaque dépôt.
Déclenchement : chaque dépôt peut lancer une revue une seule fois à l'ouverture d'une pull request, après chaque push, ou uniquement lorsque quelqu'un commente « @claude review ».

Prix et disponibilité

Il n'existe pas de tarif fixe par revue. Les revues sont facturées en fonction de l'utilisation de tokens via des crédits d'utilisation, séparément de l'utilisation incluse dans l'offre, et le coût dépend du niveau de revue, de la taille du changement et de la fréquence des revues. Les administrateurs peuvent fixer une limite de dépense mensuelle. Les organisations Enterprise éligibles peuvent obtenir au moins 10 000 $ de crédits Code Review jusqu'au 15 janvier 2027 ; les crédits expirent 30 jours après avoir été réclamés. Code Review fonctionne avec GitHub, y compris GitHub Enterprise Server, et n'est pas disponible pour les organisations utilisant la rétention nulle des données (Zero Data Retention) ou la configuration HIPAA.

L'option de GitHub, le même jour

Toujours le 15 octobre, GitHub a rendu AI Scan for pull requests disponible en version générale. Son périmètre est plus restreint : l'outil recherche les vulnérabilités de sécurité dans les changements des pull requests, dans des langages et frameworks que CodeQL ne couvre pas, comme PHP, Shell, Terraform et les Dockerfiles. Il est gratuit pour les dépôts publics ; les dépôts privés nécessitent GitHub Code Security ou Advanced Security, et aucune licence Copilot n'est requise. Ses constats sont consultatifs et ne peuvent pas bloquer les fusions.

Ce que cela signifie si vous choisissez un outil de revue

Si vous voulez un second réviseur pour les bugs et la logique, Claude Code Review couvre un périmètre plus large. Testez-le sur quelques dépôts avec des revues configurées pour s'exécuter une seule fois ou sur demande, avant de décider d'opter pour « après chaque push », ce qui multiplie le coût.

Si votre priorité est la sécurité et que vous payez déjà pour les produits de sécurité de GitHub, AI Scan s'intègre à ce que vous avez déjà. Les équipes déjà équipées de GitHub Copilot peuvent comparer les deux options : Claude Code vs GitHub Copilot.
