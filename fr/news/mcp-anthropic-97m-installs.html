Le Model Context Protocol d'Anthropic Dépasse 97 Millions d'Installations — Devient l'Infrastructure Centrale pour les Agents d'IA

Infrastructure Apr 30, 2026·Anthropic Blog

Le Model Context Protocol (MCP) d'Anthropic a dépassé les 97 millions d'installations en mars 2026.

Qu'est-ce que MCP

MCP est un standard ouvert définissant comment les modèles d'IA se connectent aux outils externes, aux bases de données et aux API. Écrivez une fois, fonctionne avec n'importe quel modèle d'IA compatible MCP.

Adoption universelle

Chaque grand fournisseur d'IA propose désormais des outils compatibles MCP : OpenAI, Google, xAI, Mistral et d'autres. Claude Code, Cursor, Windsurf et autres outils de codage IA utilisent MCP comme mécanisme principal de connexion des outils.

Pourquoi 97M est important

Avec 97 millions d'installations, MCP a atteint une adoption au niveau infrastructure — comparable à la façon dont les API REST sont devenues le standard par défaut pour les services web. C'est le standard de facto pour la communication IA-à-outil.
