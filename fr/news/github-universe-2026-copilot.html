GitHub Universe 2026 : une application Copilot de l'issue au merge, le routage multi-modèles Copilot Fusion, et Copilot pour tous les clients Enterprise

Outils Oct 28, 2026·GitHub

GitHub a profité de sa conférence Universe du 28 octobre pour repositionner GitHub Copilot, le faisant passer du statut d'assistant de codage à celui de système permettant de mener le travail à son terme. Quatre annonces comptent particulièrement pour quiconque choisit un outil de codage.

L'application Copilot

Une nouvelle application de bureau, pour l'instant proposée en téléchargement pour les Mac à puce Apple, conçue pour mener une tâche de l'issue au merge. Elle relie agents et outils à travers les projets et couvre aussi le travail périphérique au code, comme la rédaction de spécifications et l'analyse de télémétrie. En son sein, les Copilot projects, disponibles dès le lancement, exécutent le travail des agents sur plusieurs dépôts en parallèle, avec un seul endroit pour suivre la progression. Une session d'agent dans le cloud peut être suivie et pilotée depuis l'application, VS Code, la CLI ou le web.

Copilot Fusion

Fusion est un routeur de modèles : on le sélectionne dans le menu des modèles, et pour chaque requête il choisit quels modèles utiliser et comment, d'un seul modèle jusqu'à plusieurs qui rédigent, critiquent et révisent. Il est disponible en version générale dans VS Code, Copilot CLI, l'application Copilot et les IDE JetBrains. Fusion Standard est inclus dans toutes les formules, y compris Free ; Fusion High nécessite Pro+, Max, Business ou Enterprise ; Fusion Max nécessite Max, Business ou Enterprise. Il n'y a pas de frais séparés : vous payez des crédits IA pour chaque modèle qu'il sollicite.

GitHub affirme que Fusion Max a obtenu un score à deux points près de celui de Claude Opus 5.5 Max sur l'Artificial Analysis Coding Agent Index, pour moitié moins cher et en 40 % de temps en moins par tâche. Il s'agit d'une affirmation de GitHub elle-même.

Revue de code Max

La revue de code Copilot reçoit un troisième niveau, le plus poussé, Max, en préversion publique. Il mobilise plusieurs modèles à raisonnement poussé, et la documentation de GitHub situe le coût moyen à environ 10 $ en crédits IA par revue, contre environ 1,50 $ pour le niveau par défaut Balanced et 0,25 $ pour Lite.

Copilot inclus pour GitHub Enterprise

Les clients GitHub Enterprise peuvent désormais utiliser toutes les fonctionnalités de Copilot, y compris l'application, la revue de code et les automatisations, sans acheter un abonnement Copilot séparé. Ils paient les crédits IA qu'ils consomment. Pour l'instant, cela passe par les équipes commerciales de GitHub, un accès en libre-service étant promis plus tard, et les clients existants de Copilot Business et Enterprise peuvent conserver leur formule actuelle. Pour les particuliers, Copilot est affiché à 10 $ par mois pour Pro, 39 $ pour Pro+ et 100 $ pour Max.

Ce que cela signifie si vous choisissez un agent de codage

Si votre entreprise paie déjà pour GitHub Enterprise, demandez à votre administrateur de vous renseigner sur l'option basée sur les crédits avant d'acheter un agent de codage séparé : vous pourriez obtenir Copilot sans nouveau contrat par poste.

Si vous comparez Copilot à Claude Code, Fusion et la revue de code Max rapprochent les deux produits, et le coût dépend désormais des crédits consommés plutôt que du nombre de postes. Voir Claude Code vs GitHub Copilot.
