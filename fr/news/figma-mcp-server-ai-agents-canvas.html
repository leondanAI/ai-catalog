Le serveur MCP de Figma permet désormais aux agents IA d'écrire directement sur le canvas

Outils May 10, 2026·Figma Blog

Le serveur MCP (Model Context Protocol) de Figma, lancé en bêta le 4 juin 2025, permet désormais aux agents IA — notamment Cursor, Claude et des agents développés sur mesure — de créer et modifier des designs directement sur le canvas de Figma. Cette capacité étendue repose sur un nouvel outil use_figma dédié à l'écriture sur le canvas, que Figma a annoncé le 24 mars 2026.

Le serveur MCP de Figma

Le serveur MCP expose le canvas de Figma comme une interface programmable pour les agents IA. Un développeur travaillant dans Cursor peut demander à son agent de codage de générer un composant d'interface utilisateur directement dans Figma — l'agent crée des cadres (frames), applique des styles, positionne les éléments et nomme les calques sans que le développeur ait besoin de changer d'outil ou de recréer manuellement une suggestion de l'IA. Les systèmes de design et les bibliothèques de composants sont accessibles aux agents via l'interface MCP, ce qui permet une génération contextuelle respectant les tokens de design et les modèles établis.

Pourquoi c'est important

La capacité d'écriture sur le canvas du serveur MCP signifie que les agents IA ne se limitent plus à générer du code que les développeurs doivent ensuite traduire manuellement en designs — l'artefact de design lui-même peut désormais être créé et mis à jour par les agents. Cela referme une partie de la boucle entre le développement et le design assistés par IA, en permettant des flux de travail où un seul agent produit à la fois le code et le design d'interface utilisateur correspondant.
