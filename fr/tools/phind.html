GitHub Copilot est un assistant de codage agentique et multi-modèles qui va au-delà de l'autocomplétion, offrant un chat, un mode agent, des agents cloud, une revue de code et une CLI, avec des modèles disponibles de fournisseurs incluant Anthropic, OpenAI, Google, xAI, Microsoft et Moonshot.
