À propos Microsoft Copilot

Microsoft Copilot est l'assistant IA que Microsoft a intégré à Windows, Edge, Bing et aux applications Microsoft 365. Il a récemment été renommé : l'application Microsoft 365 Copilot s'appelle désormais Microsoft Copilot, et l'application Microsoft 365 Copilot Chat s'appelle désormais Microsoft Copilot Chat.

Les licences sont organisées en paliers : Copilot Chat (Basic), Microsoft 365 Copilot (Basic), qui donne un accès Copilot standard dans Word, Excel, PowerPoint et OneNote sans module complémentaire séparé, et Microsoft 365 Copilot (Premium), un module complémentaire avec un accès étendu. Microsoft a également lancé Copilot Cowork, un produit facturé à l'usage pour un travail agentique plus large, et les plans entreprise Microsoft 365 E7 incluent la licence Copilot par défaut. Lors d'un événement Windows le 7 octobre 2026, Microsoft a déclaré repositionner Copilot sur Windows, en s'éloignant d'une simple fenêtre de chat pour devenir un assistant capable d'utiliser le contexte local du PC de l'utilisateur et d'agir dessus.

Au quotidien, Copilot achemine les requêtes via un sélecteur de modèle proposant les options Auto, Quick response et Think deeper, plutôt que d'exposer des numéros de version de modèle spécifiques. Les modèles d'Anthropic sont également disponibles dans les expériences sous licence applicables ; le menu de modèles de Word, par exemple, inclut désormais un modèle Anthropic comme modèle par défaut pour les tâches à raisonnement poussé. Microsoft a annoncé que Copilot pourra utiliser le contexte local et exécuter des modèles locaux, cette fonctionnalité arrivant sur les PC Copilot+ dans les prochains mois, et a déployé Microsoft Execution Containers, une couche de confinement pilotée par des règles pour les agents IA s'exécutant sur Windows, désormais généralement disponible.

Les tarifs n'ont pas pu être vérifiés sur les pages de tarification officielles de Microsoft au moment de cette évaluation ; les montants en dollars précis sont donc omis ici. Ce qui est confirmé, c'est la structure de paliers ci-dessus : une expérience de chat basique, un palier intégré basique, un module complémentaire Premium payant, et le nouveau produit Cowork facturé à l'usage. Copilot Chat (Basic) est inclus sans coût supplémentaire pour les utilisateurs disposant d'un abonnement professionnel Microsoft 365 éligible, mais ce n'est pas un plan gratuit autonome ouvert au grand public.

Les principales limites sont que les licences et la nomenclature de Microsoft sont réellement difficiles à suivre entre les références grand public, Business et entreprise, que les tarifs actuels ne sont pas publiés de manière transparente, et que les fonctionnalités intégrées les plus puissantes nécessitent une licence Microsoft 365 Copilot payante plutôt que d'être disponibles pour les utilisateurs occasionnels. Les fonctionnalités de contexte local et d'action locale récemment annoncées ne sont pas encore disponibles et ne devraient arriver sur les PC Copilot+ que dans les prochains mois.

Copilot est le plus pertinent pour les personnes et organisations déjà intégrées à Microsoft 365 qui souhaitent un assistant capable d'accéder à leurs documents, e-mails et calendrier plutôt qu'un chatbot autonome, ainsi que pour les utilisateurs Windows qui observent Copilot évoluer d'un panneau de chat vers un agent au niveau du PC.

Questions fréquemment posées

Qu'est-ce que Microsoft Copilot ?
Microsoft Copilot est l'assistant IA de Microsoft intégré à Windows, Microsoft 365 (Word, Excel, Outlook, Teams), Edge et Bing. Il utilise par défaut les modèles d'OpenAI, les modèles d'Anthropic étant également disponibles dans les expériences sous licence applicables, pour aider dans les tâches à travers l'écosystème Microsoft.
Combien coûte Microsoft Copilot ?
La licence de Copilot se divise en paliers : Copilot Chat (Basic), Microsoft 365 Copilot (Basic) pour l'accès intégré à Word, Excel, PowerPoint et OneNote, un module complémentaire Microsoft 365 Copilot (Premium), et le nouveau Copilot Cowork facturé à l'usage. Les tarifs actuels en dollars pour ces paliers n'ont pas pu être vérifiés sur les pages de tarification de Microsoft au moment de la rédaction.
Que peut faire Microsoft Copilot dans Excel ?
Copilot dans Excel peut générer des formules, créer des tableaux croisés dynamiques, résumer des données, créer des graphiques et répondre à des questions sur votre feuille de calcul en langage naturel.
Microsoft Copilot est-il la même chose que GitHub Copilot ?
Non. Microsoft Copilot est un assistant IA généraliste pour Windows et les applications M365. GitHub Copilot est un produit distinct axé sur la complétion de code et le développement, disponible sur github.com/features/copilot.
