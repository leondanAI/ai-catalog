# Claude Code обогнал GitHub Copilot: какими AI-инструментами пишут код разработчики в 2026 году и почему

_Два больших опроса этой осени сходятся: Claude Code обогнал GitHub Copilot. По данным JetBrains (более 15 000 профессиональных разработчиков), доля тех, кто пользуется Claude Code на работе, выросла с 18% в январе до 39% летом, а у Copilot упала до 21%, у Cursor до 12%. Опрос Stack Overflow (более 30 000 человек) показывает, почему инструменты меняют: ради качества результата, а не ради цены._

Два крупнейших опроса разработчиков этого года вышли с разницей в несколько недель, и картина в них одна. **Claude Code**, агент для программирования от Anthropic, стал самым популярным AI-инструментом для кода и обогнал **GitHub Copilot**, который годами был лидером рынка. Опросы показывают и то, для чего разработчики на самом деле используют эти инструменты, и то, что заставляет их переходить на другие.


## JetBrains: Claude Code вырос вдвое за полгода

С мая по июль 2026 года JetBrains спросила более 15 000 профессиональных разработчиков по всему миру, какими AI-инструментами для кода они пользуются на работе. Результаты вышли в августе в рамках _Developer Ecosystem Survey 2026_:

**Claude Code: 39%**, в январе было 18%. В США — 47%. Для 31% разработчиков это основной инструмент.  
**GitHub Copilot: 21%**, годом ранее было 29%.  
**OpenAI Codex: 16%**, в январе было 3% — самый быстрый рост в опросе.  
**Cursor: 12%**, в январе было 18%.  
**JetBrains AI: около 9%**, **OpenCode: 7%**, **Google Antigravity: 6%**.

С агентами теперь работают почти все: 90% профессиональных разработчиков пользовались AI-агентом для кода на работе хотя бы раз в неделю, 68% — каждый день.


## Stack Overflow: тот же лидер и причины выбора

Stack Overflow опубликовал свой 16-й ежегодный опрос разработчиков 6 октября. За семь недель в нём участвовали более 30 000 человек. Среди агентов для кода лидируют **Claude Code (66%)** и **GitHub Copilot (59%)**. По моделям, пишет Stack Overflow, Anthropic и OpenAI идут вровень, а Google заметно отстаёт на третьем месте.

Почему проценты так отличаются от JetBrains? Опросы задают разные вопросы разным группам. JetBrains считает всех профессиональных разработчиков и спрашивает, чем они пользуются на работе; цифры Stack Overflow относятся к вопросу про агентов для кода, где один человек может назвать несколько инструментов. Напрямую сравнивать проценты нельзя, но порядок в обоих опросах одинаковый: Claude Code первый, Copilot второй.

Самое полезное в данных Stack Overflow — почему люди меняют инструменты. Из 13 144 ответивших:

**33,7%** не меняли AI-инструменты.  
**25,1%** перешли ради лучшего качества результата.  
**10,6%** перешли, потому что работодатель потребовал или порекомендовал другой инструмент.  
**7,4%** перешли ради лучшей интеграции в свою работу.  
**6,4%** перешли ради более низкой цены.

Тот же приоритет виден и в другом вопросе: при выборе модели и составлении запросов 75% разработчиков называют важным качество и только 38% — стоимость.


## Для чего разработчики используют AI

Самые частые задачи (ответили 12 547 человек): писать код в знакомой области (69%), отлаживать и рефакторить (64%), отвечать на простые технические вопросы (59%), писать тесты (58%) и писать код в незнакомой области (56%).

Доверие при этом ограничено. Только 48% доверяют AI, когда ответ легко проверить, а 93% говорят, что им нужно видеть источники, чтобы поверить ответу.


## Что это значит, если вы выбираете инструмент для кода

**Если нужен агент, который берёт задачу целиком** — меняет несколько файлов, запускает тесты и чинит то, что сломалось, — [Claude Code](https://aitoolfit.ai/ru/tools/claude-code.html) сейчас самый частый выбор профессионалов. Быстрее всех растёт альтернатива от OpenAI — Codex.

**Если компания уже платит за GitHub**, [GitHub Copilot](https://aitoolfit.ai/ru/tools/github-copilot.html) по-прежнему второй по популярности, а примерно каждый десятый разработчик сменил инструмент потому, что так решил работодатель. Сравните их напрямую: [Claude Code или GitHub Copilot](https://aitoolfit.ai/ru/compare/claude-code-vs-github-copilot.html).

**Если удобнее работать в редакторе, построенном вокруг AI**, [Cursor](https://aitoolfit.ai/ru/tools/cursor.html) в этом году потерял долю, но им по-прежнему пользуется каждый восьмой профессиональный разработчик: [Cursor или Copilot](https://aitoolfit.ai/ru/compare/cursor-vs-copilot.html).

**Если нужен открытый код**, [OpenCode](https://aitoolfit.ai/ru/tools/opencode.html) дошёл до 7%: [OpenCode или Claude Code](https://aitoolfit.ai/ru/compare/opencode-vs-claude-code.html).

Главный вывод обоих опросов: разработчики выбирают инструмент по качеству результата, а не по цене. Прежде чем определиться, попробуйте два-три инструмента на реальной задаче из своего проекта и проверяйте код, который они пишут, до того как он уйдёт в работу.
